דבר ראשון להוריד את ה-Reel
משם זה מתפצל לשני חלקים, סרטון וסאונד
את סאונד אפשר להעביר לffmpeg ולהוציא **_ספקטוגרם_**
את הסרטון אפשר להוציא לפריימים ולהעלות
# הורדה
באמצעות _Instagram-Reel-Scraper_ (סקריפט שמצאתי באינטרנט) אפשר להוציא את המקור של הסרטון, משם אפשר עם `jq` להוציא את הסרטון ואת הסאונד

בשביל הסרטון:
```bash
jq '.extensions.all_video_dash_prefetch_representations[0].representations[0].base_url' -r
```
בשביל הסאונד:
```bash
jq '.extensions.all_video_dash_prefetch_representations[0].representations[-1].base_url' -r
```
# סרטון
משם לדחוף את זה ל-frame extractor ולהשיג את הפריימים
# סאונד
זה ספציפית להוציא מתוך הstdin
```bash
ffmpeg -i pipe:0 lavfi showspectrumpic=s=800x400:mode=separate^Cpectogra
m.png
```
הרעיון הכללי הוא
```bash
| jq '.extensions.all_video_dash_prefetch_representations[0].representations[-1].base_url' -r | xargs -I {} curl {} | ffmpeg -i pipe:0 -lavfi showspectrumpic=s=800x400:mode=separate spectogram.png
```
