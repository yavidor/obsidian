# הגדרה
תהיינה $f,g$ [[פונקציה|פונקציות]] שמוגדרות ו[[נגזרת|גזירות]] בסביבה מנוקבת של $a$ כך שמתקיים
א.
$$
\lim_{ x \to a } f\left( x \right) =\lim_{ x \to a } g\left( x \right) =0
$$
ב.
קיים הגבול $\lim_{ x \to a } \frac{f'\left( x \right)}{g'\left( x \right)}$

אזי מתקיים
$$
\lim_{ x \to a } \frac{f\left( x \right) }{g\left( x \right) }= \lim_{ x \to a } \frac{f'\left( x \right) }{g'\left( x \right) }
$$

> [!NOTE] וואריאציות
> בתנאי הראשון, ניתן להחליף את $a$ ב $\pm \infty$


# הוכחה
נרחיב את $f,g$ כך שיהיו מוגדרות גם ב $x=a$ על ידי הגדרת $f\left( a \right)=g\left( a \right)=0$, כך ההרחבות [[רציפות]] בכל הסביבה של $a$
נוכיח כי
$$
\lim_{ x \to a^{+} } \frac{f\left( x \right) }{g\left( x \right) }=\lim_{ x \to a^{+} } \frac{f'\left( x \right) }{g'\left( x \right) }
$$
וכי
$$

\lim_{ x \to a^{-} } \frac{f\left( x \right) }{g\left( x \right) }=\lim_{ x \to a^{-} } \frac{f'\left( x \right) }{g'\left( x \right) }
$$
ומכאן נסיק
$$
\lim_{ x \to a } \frac{f\left( x \right) }{g\left( x \right) }=\lim_{ x \to a } \frac{f'\left( x \right) }{g'\left( x \right) }
$$
כנדרש

נוכיח עבור הגבול הימני, ההוכחה עבור הגבול השמאלי דומה.
יהא $h>0$ מספר קטן כך ש-$a+h$ שייך לסביבה בה הפונקציות מוגדרות וגזירוץ.
נפעיל את משפט קושי על $f,g$ בקטע $\left[ a,a+h \right]$
$f,g$ רציפות ב$\left[ a,b \right]$ וגזירות ב $\left( a,b \right)$
$g'\left( x \right)\neq 0$ בקטע (השלם כאן ממירה ונסטיה) מהנתון שקיים הגבול $\lim_{ x \to a } \frac{f'\left( x \right)}{g'\left( x \right)}$

לכן ממשפט קושי קיים $0<h'<h$ כך ש
$$
\frac{f'\left( a+h' \right) }{g'\left( a+h' \right) } = \frac{f\left( a+h \right) -f\left( a \right) }{g\left( a+h \right) -g\left( a \right) }= \frac{f\left( a+h \right) }{g\left( a+h \right) }
$$
כעת נשאיף את $h$ ל-$0^{+}$, לכן מהגבול גם $h'\to 0^{+}$ ולכן
$$
\lim_{ x \to a^{+} } \frac{f\left( x \right) }{g\left( x \right) }= \lim_{ x \to a^{+}} \frac{f'\left( x \right) }{g'\left( x \right) } 
$$
$\blacksquare$
