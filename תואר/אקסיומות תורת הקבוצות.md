# ${1}$ - אקסיומת ההיקף
קבוצה מוגדרת ע"י איבריה
# ${2}$ - אקסיומת הקבוצה הריקה
 קיימת קבוצה שאין לה איברים
# ${3}$ - אקסיומת הזיווג
אם $A,B$ קבוצות אזי $\left\{ A,B \right\}$ קבוצה
# ${4}$ - אקסיומת האיחוד
אם $\mathcal{A}$ קבוצה אזי $\bigcup \mathcal{A}$  קבוצה
# ${5}$ - אקסיומת ההפרדה
אם $A$ קבוצה ו-$\varphi \left( x \right)$ ביטוי (כש-$x$ משתנה חופשי), אז יש קבוצה שאיבריה הם כל האיברים $a\in A$ שעוברם $\varphi \left( a \right)$ פסוק אמת.
