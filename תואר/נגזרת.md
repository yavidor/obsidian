תהא $f$ [[פונקציה]] המוגדרת בסביבה של $x_{0}$.
נאמר ש-$f$ <u>גזירה</u> ב-$x_{0}$ אם קיים [[גבול]]
$$
\boxed{\lim_{ x \to x_{0} } \frac{f\left( x \right) -f\left( x_{0} \right) }{x-x_{0}}}
$$
(שמתי תיבה כי זה עד כדי כך חשוב)
כאשר הגבול קיים, הוא נקרא <u>הנגזרת</u> של $f$ ב-$x_{0}$ ומסומן ב-$f'\left( x \right)$ או $\frac{df}{dx}\left( x_{0} \right)$
# נגזרת כשיפוע
הנגזרת בנקודה מסוימת היא השיפוע של הפונקציה באותה נקודה, ואז אפשר להוציא ישר משיק לפי נוסחת הישר
$$
y=f\left( x_{0} \right) +f'\left( x_{0} \right)\left( x-x_{0} \right) 
$$
# טענה על רציפות
אם $f$ גזירה אזי $f$ [[פונקציה#רציפות|רציפה]] ב-$x_{0}$
## הוכחה
צריך להראות כי $f\left( x \right)-f\left( x_{0} \right)\xrightarrow{x\to x_{0}}0$
$$
f\left( x \right) -f\left( x_{0} \right) = \underset{ \xrightarrow{x\to x_{0}} f'\left( x_{0} \right) }{ \frac{f\left( x \right) -f\left( x_{0} \right) }{x-x_{0}} } \cdot \underset{ \xrightarrow{x\to x_{0}} 0}{ \left( x-x_{0} \right) } \underset{ \text{Limit arithmatics} }{ \implies } f\left( x \right) -f\left( x_{0} \right) \xrightarrow{x\to x_{0}}0
$$
## כיוון שני
האם כל פונקציה רציפה ב-$x_{0}$ היא בהכרח גזירה ב-$x_{0}$?
מסתמן כי לא, נלקח למשל את $f\left( x \right)=\left| x \right|$ כפונקציה ו-$x_{0}$ כנקודה
### הוכחה
יש להראות כי $\lim_{ x \to 0 } \frac{\left| x \right| -\left| 0 \right| }{x-0}$ לא קיים. על מנת להראות זאת, מספיק להראות כי $\lim_{ x \to 0^{+} } \frac{\left| x \right|}{x},\lim_{ x \to 0^{-} } \frac{\left| x \right|}{x}$ קיימים ואינם שווים
ואכן
$$
\begin{gather}
\lim_{ x \to 0^{+} } = \lim_{ x \to 0^{+} }  \frac{x}{x}= \lim_{ x \to 0^{+} } 1 =1 \\

\lim_{ x \to 0^{-} } = \lim_{ x \to 0^{-} }  \frac{-x}{x}= \lim_{ x \to 0^{-} } -1 =-1 \\
\end{gather}
$$
# הגדרה
$f$ גזירה מימין ב-$x_{0}$ אם היא מוגדרת בסביבה ימנית של $x_{0}$ וקיים הגבול $\lim_{ x \to x_{0}^{+} } \frac{f\left( x \right)-f\left( x_{0} \right)}{x-x_{0}}$
מסומן ב-$f'_{+}\left( x_{0} \right)$
באותו האופן מגדירים גזירות משמאל.
# נגזרות של מניפולציה על פונקציות
אם $f,g$ גזירות ב-$x_{0}$, $c\in \mathbb{R}$
אזי מתקיים
א.
$$
\left( c\cdot f \right)'\left( x_{0} \right)=c\cdot f'\left( x_{0} \right)
$$
ב.
$$
\left( f+g \right)'\left( x_{0} \right) =f'\left( x_{0} \right) +g'\left( x_{0} \right) 
$$
ג.
$$
\left( f \cdot g \right)'\left( x_{0} \right) =f'\left( x_{0} \right) \cdot g\left( x_{0} \right) + f\left( x_{0} \right) \cdot g'\left( x_{0} \right) 
$$
ד.
$$
\left( \frac{f}{g} \right)' = \frac{f'\left( x_{0} \right) \cdot g\left( x_{0} \right) -g'\left( x_{0} \right) \cdot f\left( x_{0} \right)  }{g^{2}\left( x_{0} \right) }
$$
$g\left( x \right)$ שונה מאפס בסביבה של $x_{0}$.
## הוכחה
ההוכחה נמצאת ב[[תואר/סיכומים/סמסטר א/אינפי 1/הרצאה 18#הוכחה לתכונות נגזרת]]
# משפט מפחיד
תהא $f$ מוגדרת בסביבה של $x_{0}$, אזי הטענות הבאות שקולות
1. $f$ גזירה ב-$x_{0}$
2. קיימים $A\in \mathbb{R}$ ופונקציה $\epsilon$ (כן, אפסילון)המוגדרת בסביבה של $0$ ומקיימת $\lim_{ x \to 0 }\epsilon \left( x \right)=0$ 
כך ש: $f\left( x \right)=f\left( x_{0} \right)+A\cdot\left( x-x_{0} \right)+\epsilon \left( x-x_{0} \right)\cdot \left( x-x_{0} \right)$

> [!NOTE] הערה
> כשב' מתקיים אזי $f'\left( x_{0} \right)=A$

> [!TIP] שימוש במשפט
> השימוש שנראה למשפט הוא שעל מנת להוכיח שפונקציה $f$ גזירה ב-$x_{0}$
> מספיק להציג אותה כ: $f\left( x \right)=f\left( x_{0} \right)+A\cdot \left( x-x_{0} \right)+\epsilon \left( x-x_{0} \right)\left( x-x_{0} \right)$
> ונשים לב ש-$\epsilon \left( x-x_{0} \right)\to 0$ כש-$x-x_{0}\to 0$
> ובנוסף, ברגע שמצאנו הצגה כזו של פונקציה. אנחנו יודעים כי $A=f'\left( x \right)$

> [!NOTE] עוד הערה, וואו
> לפעמים יהיה יותר נוח לכתוב $x=x_{0}+h$ ואז
> $f\left( x_{0}+h \right)= f\left( x_{0} \right)+ A\cdot h+\epsilon \left( h \right)\cdot h$ 
> ונשים לב ש-$\epsilon \left( h \right)\to 0$ כש-$h \to 0$
> זה בדיוק אותו דבר אבל קצת נוח יותר לכתוב

## הוכחה
נתחיל עם $2 \impliedby 1$
נגדיר $\epsilon \left( h \right):=\frac{f\left( x_{0}+h \right)-f\left( x_{0} \right)}{h}-f'\left( x_{0} \right)$ ל-$h \neq 0$ 
מתקיים
$$
f\left( x_{0}+h \right) =f\left( x_{0} \right) +f'\left( x_{0} \right) \cdot h + \epsilon \left( h \right) \cdot h
$$
(פשוט בודדנו את $f\left( x_{0}+h \right)$ והעברת אגפים)
כמו כן $\epsilon \left( h \right)\xrightarrow{h\to_{0}}0$ כיוון ש-$f'\left( x \right)=\lim_{ h \to 0 } \frac{f\left( x_{0}+h \right)-f\left( x_{0} \right)}{h}=0$

עכשיו נוכיח $1 \impliedby 2$
נתונה הצגה של $f$:
$$
f\left( x_{0}+h \right) -f\left( x_{0} \right) =A\cdot h+\epsilon \left( h \right) \cdot h
$$
וש $\epsilon \left( h \right)\xrightarrow{h\to 0}0$
$$
\frac{f\left( x_{0}+h \right) -f\left( x_{0} \right) }{h}=A+\epsilon \left( h \right) 
$$
לכן
$$
\begin{gather}
\lim_{ h \to 0 } \frac{f\left( x_{0}+h \right) -f\left( x_{0} \right) }{h} = \lim_{ h \to 0 } ~\underset{ \to A }{ A }+\epsilon \underset{ \to 0 }{ \left( h \right) } \\
\lim_{ h \to 0 } \frac{f\left( x_{0}+h \right) -f\left( x_{0} \right) }{h}=A
\end{gather}
$$
וזו הגדרת הנגזרת, לכן $f$ גזירה ב-$x_{0}$ ו$A=f'\left( x_{0} \right)$
