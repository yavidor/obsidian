# הגדרה
תהא $f$ [[נגזרת|גזירה]] ב$\left[ a,b \right]$ (כלומר בכל נקודה ב$\left( a,b \right)$ היא גזירה ובקצוות יש את הנגזרות החד כיווניות $f_{+}'\left( a \right),f_{-}'\left( b \right)$ ) ויהא $\lambda \in \mathbb{R}$ בין $f_{+}'\left( a \right)$ ל-$f_{-}'\left( b \right)$ (לא כולל הקצוות), אזי קיים $x \in \left( a,b \right)$ כך ש-$f'\left( x \right)=\lambda$
# הוכחה
בה"כ $f'_{+}\left( a \right)>\lambda>f_{-}'\left( b \right)$
נתבונן בפונקציה $h\left( x \right)=f\left( x \right)-\lambda x$
$h$ גזירה ב$\left[ a,b \right]$ כהפרש של פונקציות גזירות ומתקיים
$$
\begin{gather}
h_{+}'\left( a \right) = f'_{+}-\lambda>0 \\
h_{-}'\left( b \right) =f_{-}'\left( b \right) -\lambda<0
\end{gather}
$$
נשים לב ש$a,b$ אינן נקודות מקסימות של $h$ כי
$$
0< h_{+}'\left( a \right) =\lim_{ x \to a^{+} } \frac{h\left( x \right) -h\left( a \right) }{x-a}\implies \exists x \in \left( a,b \right) : h\left( x \right) >h\left( a \right) 
$$
באותו האופן
$$

0> h_{-}'\left( b \right) =\lim_{ x \to a^{+} } \frac{h\left( x \right) -h\left( b \right) }{x-b}\implies \exists x \in \left( a,b \right) : h\left( x \right) <h\left( b \right) 
$$
מ[[משפט ויירשטראס]] קיימת ל-$h$ נקודת מקסימות $x^{*}\in \left[ a,b \right]$ אבל $x^{*}\neq a,b$ ולכן $x^{*}\in \left( a,b \right)$
לכן מ[[משפט פרמה]]
$$
0=h'\left( x^{*} \right) = f'\left( x^{*} \right) -\lambda \implies f'\left( x^{*} \right) =\lambda
$$
$\blacksquare$
