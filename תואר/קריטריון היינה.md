## הגדרה במובן הרחב לגבול שווה לאינסוף בנקודה מסויימת
תהא $f$ [[פונקציה]] המוגדרת בסביבה נקובה של $x_{0}$ אזי הטענות הבאות שקולות
1. $\lim_{ x \to x_{0} }f\left( x \right)=\infty$
2. לכל סדרה $\left( x_{n} \right)^\infty_{n=1}$ כך ש $x_{n}\xrightarrow{n\to \infty}x_{0}$ מתקיים $f\left( x_{n} \right)\xrightarrow{n\to \infty}\infty$
### הוכחה
נוכיח $2\impliedby 1$
תהא $x_{n}\xrightarrow{n\to \infty}x_{0}$, נוכיח $\lim_{ n \to \infty }f\left( x_{n} \right)=\infty$
יהא $M\in \mathbb{R}$ עלינו למצוא $N$ כך ש$f\left( x_{n} \right)>M$ לכל $n\geq N$
$\impliedby \lim_{ x \to x_{0} }f\left( x \right)=\infty$ קיימת $\delta$ כך ש$0<\left| x-x_{0} \right|<\delta$, אזי $f\left( x \right)>M$ש
כיוון ש $x_{n}\xrightarrow{n\to \infty}x_{0}$ קיים $N$ כך ש $0<\left| x_{n}-x_{0} \right|<\delta$ לכל $n\geq N$ ולכן גם $f\left( x_{n} \right)>M$ לכל $n\geq N$

נוכיח $1 \impliedby 2$
נשים לב שזה שקול לכך ש"לא 1" גורר "לא 2"
נניח $\lim_{ x \to x_{0} }f\left( x \right)\neq \infty$, לכן קיים $M_{0}\in \mathbb{R}$ כך שלכל $\delta>0$ קיים $x$ כך ש$0<\left| x-x_{0} \right|<\delta$ ו$f\left( x \right)<M_{0}$
נגדיר $\left( x_{n} \right)^{\infty}_{n=1}$ באופן הבא:
האיבר ה$n$ - $x_{n}$  יבחר להיות אותו $x_{n}$ כך ש $0<\left| x_{n}-x_{0} \right|< \frac{1}{n}$ וגם $f\left( x_{n} \right)\leq M_{0}$ ולכן $f\left( x_{n} \right)$ חסומה מלעיל על ידי $M_{0}$ ולכן איננה מתכנסת ל$\infty$ וכמו כן $x_{0}-\frac{1}{n}<x_{n}< x_{0} +\frac{1}{n}$ (לא הבנתי מה אכפת לי)


# דוגמה לאי קיום גבול בנקודה
$f\left( x \right)=\sin \left( \frac{1}{x} \right)$ עם תחום הגדרה $\left( -1,1 \right) \setminus \left\{ 0 \right\}$
## טענה
ל$f\left( x \right)$ לא קיים גבול ב-$0$.
### הוכחה
לפי היינה, מספיק למצוא שתי סדרות. $\left( x_{n} \right),\left( y_{n} \right)$ כך ש $x_{n}\to 0$, $y_{n}\to 0$ אבל $\lim_{ n \to \infty }f\left( x_{n} \right)=K,\lim_{ n \to \infty }f\left( y_{n} \right)=L$ כאשר $L\neq K$
דוגמה
$$
\begin{gather}
x_{n}=\frac{1}{2\pi n+ \frac{\pi}{2}} \\
\sin\left( \frac{1}{x_{n}} \right)=\sin\left( 2\pi n+\frac{\pi}{2} \right)=\sin\left( \frac{\pi}{2} \right)=1\implies \lim_{ n \to \infty } f\left( x_{n} \right) =1, x_{n}\xrightarrow{n\to \infty}0\\
y_{n}=\frac{1}{2\pi n} \\
\sin \left( \frac{1}{y_{n}} \right) =\sin(2\pi n)=0\implies \lim_{ n \to \infty } f\left( y_{n} \right) =0,y_{n}\xrightarrow{n\to \infty}=0
\end{gather}
$$
