# תרגיל 1
חשבו בעזרת כלל לייבניץ (גזירה תחת סימן האינטגרל)
$$
\alpha \in	 \left[ 0,1 \right] ,I\left( \alpha \right) = \int_{0}^{1} \frac{1}{1+\alpha e^{ x }}  \, dx 
$$
## פתרון 1
נגדיר $f\left( x,\alpha \right)= \frac{1}{1+\alpha e^{ x }}$ רציפה במלבן $\left[ 0,1 \right]\times \left[ 0,1 \right]$ (השמאלי כי אלו תחומי האינטגרל והימני כי זה התחום של $\alpha$)
אנחנו יודעים שהיא אכן רציפה כי היא אלמנטרית בתחום הגדרתה
לכן אם נגדיר
$$
I\left( \alpha \right)  = \int_{0}^{1} f\left( x,\alpha \right)  \, dx 
$$
נחשב
$$
	\frac{ \partial f }{ \partial \alpha } =-\frac{e^{ x }}{\left( 1+\alpha e^{ x } \right) ^{2}}
$$
רציפה גם  היא באותו המלבן לכן
$$
	\begin{gather}
	\frac{dI}{d\alpha} = I'\left( \alpha \right) = \frac{d}{d\alpha}\int_{0}^{1} \frac{1}{1+\alpha e^{ x }} \, dx  \\
	= \int_{0}^{1} \frac{ \partial  }{ \partial \alpha } \left( \frac{1}{1+\alpha e^{ x }} \right)   \, dx  = -\int_{0}^{1} \frac{e^{ x }}{\left( 1+\alpha e^{ x } \right) ^{2}} \, dx 
	\end{gather}
$$
נעשה הצבה של $t=e^{ x }$ ונקבל (לאחר הפרדה למקרים כאשר $\alpha=0$)
$$
	\frac{1-e}{\left( 1+\alpha \right) \left( 1+\alpha e \right) }
$$
ולכן
$$
	I'\left( \alpha \right) =\frac{1-e}{\left( 1+\alpha \right) \left( 1+\alpha e \right) }
$$
