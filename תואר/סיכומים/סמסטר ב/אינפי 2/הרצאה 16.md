# למה
$f$ [[דיפרנציאבילית]] ב-$\left( x_{0},y_{0} \right)$ אם ורק אם
$$
	f\left( x_{0}+\Delta x,y_{0}+\Delta y \right) = A\Delta x + B\Delta y + \alpha \left( \Delta x,\Delta y \right) \Delta x  + B\left( \Delta x,\Delta y \right) \Delta y 
$$
כאשר
$$
	\lim_{ \left( s,t \right)  \to \left( 0,0 \right)  } \alpha \left( s,t \right) =\lim_{ \left( s,t \right)  \to \left( 0,0 \right)  } B\left( s,t \right) =0
$$
## הוכחה
נסמן $\epsilon \left( s,t \right)=\alpha \left( s,t \right)\cdot s + \beta \left( s,t \right)\cdot t$. עילנו להראות ש
$$
	\lim_{ \left( s,t \right)  \to \left( 0,0 \right)  } = \frac{\epsilon \left( s,t \right) }{\sqrt{s^{2}+t^{2}}}=0
$$
מתקיים
$$
	\begin{gather}
	\left| \epsilon \left( s,t \right)  \right| \leq \sqrt{\alpha^{2}\left( s,t \right) +\beta^{2}\left( s,t \right) } \sqrt{s^{2}+t^{2}} \\
	\left< (\alpha \left( s,t \right) ,\beta \left( s,t \right) ) \right> 
	\end{gather}
$$
# הנגזרת המכוונת
(Directional Derivative)
הגדרה, יהי $v\neq_{0}$ [[וקטור]] ב-$\mathbb{R}^{2}$  אז
$$
\frac{ \partial f }{ \partial v } \left( x_{0},y_{0} \right)  = \lim_{ t \to 0^{+} } \frac{f\left( \left( x_{0},y_{0} \right) +v \right) -f\left( x_{0},y_{0} \right) }{t}
$$
סימון אחר, $D_{v}f\left( x_{0},y_{0} \right)$
# משפט
אם $f$ דיפרנציאבילית ב-$\left( x_{0},y_{0} \right)$ אז $\frac{ \partial f }{ \partial v }$ קיימת לכל $0\neq v \in \mathbb{R}^{2}$
אם $v=\left( v_{1},v_{2} \right)$ אז
$$
	\frac{ \partial f }{ \partial v } \left( x_{0},y_{0} \right) = v_{1} \frac{ \partial f }{ \partial x } \left( x_{0},y_{0} \right) + v_{2} \frac{ \partial f }{ \partial y } \left( x_{0},y_{0} \right) 
$$
## הוכחה
$$
	\begin{gather}
	
	\frac{f\left( \left( x_{0},y_{0} \right) +tv \right) -f\left( x_{0},y_{0} \right) }{t}  \\
	= \frac{1}{t}\left(\frac{ \partial f }{ \partial x } \left( x_{0},y_{0} \right) \left( tv_{1} \right) + \frac{ \partial f }{ \partial y } \left( x_{0},y_{0} \right) \left( tv_{2} \right) +\epsilon \left( tv_{1},tv_{2} \right)  \right)\\
	\frac{ \partial f }{ \partial x } \left( x_{0},y_{0} \right)v_{1} + \frac{ \partial f }{ \partial y } \left( x_{0},y_{0} \right) v_{2} + \frac{\epsilon\left(tv_{1},tv_{2}  \right) }{t} \\
	\xrightarrow{ t\to o^{+} } \frac{ \partial f }{ \partial x } \left( x_{0},y_{0} \right) v_{1} + \frac{ \partial f }{ \partial y } \left( x_{0},y_{0} \right) v_{2}
	\end{gather}
$$
