# למה
$f$ [[דיפרנציאבילית]] ב-$\left( x_{0},y_{0} \right)$ אם ורק אם
$$
	f\left( x_{0}+\Delta x,y_{0}+\Delta y \right) = A\Delta x + B\Delta y + \alpha \left( \Delta x,\Delta y \right) \Delta x  + B\left( \Delta x,\Delta y \right) \Delta y 
$$
כאשר
$$
	\lim_{ \left( s,t \right)  \to \left( 0,0 \right)  } \alpha \left( s,t \right) =\lim_{ \left( s,t \right)  \to \left( 0,0 \right)  } B\left( s,t \right) =0
$$
## הוכחה
נסמן $\epsilon \left( s,t \right)=\alpha \left( s,t \right)\cdot s + \beta \left( s,t \right)\cdot t$. עילנו להראות ש
$$
	\lim_{ \left( s,t \right)  \to \left( 0,0 \right)  } = \frac{\epsilon \left( s,t \right) }{\sqrt{s^{2}+t^{2}}}=0
$$
מתקיים
$$
	\begin{gather}
	\left| \epsilon \left( s,t \right)  \right| \leq \sqrt{\alpha^{2}\left( s,t \right) +\beta^{2}\left( s,t \right) } \sqrt{s^{2}+t^{2}} \\
	\left< (\alpha \left( s,t \right) ,\beta \left( s,t \right) ) \right> 
	\end{gather}
$$
# הנגזרת המכוונת
(Directional Derivative)
הגדרה, יהי $v\neq_{0}$ [[וקטור]] ב-$\mathbb{R}^{2}$  אז
$$
\frac{ \partial f }{ \partial v } \left( x_{0},y_{0} \right)  = \lim_{ t \to 0^{+} } \frac{f\left( \left( x_{0},y_{0} \right) +v \right) -f\left( x_{0},y_{0} \right) }{t}
$$
סימון אחר, $D_{v}f\left( x_{0},y_{0} \right)$
# משפט
אם $f$ דיפרנציאבילית ב-$\left( x_{0},y_{0} \right)$ אז $\frac{ \partial f }{ \partial v }$ קיימת לכל $0\neq v \in \mathbb{R}^{2}$
אם $v=\left( v_{1},v_{2} \right)$ אז
$$
	\frac{ \partial f }{ \partial v } \left( x_{0},y_{0} \right) = v_{1} \frac{ \partial f }{ \partial x } \left( x_{0},y_{0} \right) + v_{2} \frac{ \partial f }{ \partial y } \left( x_{0},y_{0} \right) 
$$
## הוכחה
$$
	\begin{gather}
	
	\frac{f\left( \left( x_{0},y_{0} \right) +tv \right) -f\left( x_{0},y_{0} \right) }{t}  \\
	= \frac{1}{t}\left(\frac{ \partial f }{ \partial x } \left( x_{0},y_{0} \right) \left( tv_{1} \right) + \frac{ \partial f }{ \partial y } \left( x_{0},y_{0} \right) \left( tv_{2} \right) +\epsilon \left( tv_{1},tv_{2} \right)  \right)\\
	\frac{ \partial f }{ \partial x } \left( x_{0},y_{0} \right)v_{1} + \frac{ \partial f }{ \partial y } \left( x_{0},y_{0} \right) v_{2} + \frac{\epsilon\left(tv_{1},tv_{2}  \right) }{t} \\
	\xrightarrow{ t\to 0^{+} } \frac{ \partial f }{ \partial x } \left( x_{0},y_{0} \right) v_{1} + \frac{ \partial f }{ \partial y } \left( x_{0},y_{0} \right) v_{2}
	\end{gather}
$$
סימון
$$
	\begin{gather}
	\nabla f= \left( \frac{ \partial f }{ \partial x } ,\frac{ \partial f }{ \partial y }  \right)  \\
	\left( \nabla f \right) \left( x_{0},y_{0} \right) = \left( \frac{ \partial f }{ \partial x } \left( x_{0},y_{0} \right) ,\frac{ \partial f }{ \partial y } \left( x_{0},y_{0} \right)  \right) 
	\end{gather}
$$
נקרא Gradiant
או Nabla
$$
	\frac{ \partial f }{ \partial v } \left( x_{0},y_{0} \right) = \left< \nabla f\left( x_{0},y_{0} \right) ,v \right> 
$$

נתבונן בוקטורים $v$ המקיימים $\lVert v \rVert=1$
$$
	\begin{gather}
	\sup_{v:\lVert v \rVert =1} \frac{ \partial f }{ \partial v } \left( x_{0},y_{0} \right) =? \\
	\inf{v:\lVert v \rVert =1} \frac{ \partial f }{ \partial v } \left( x_{0},y_{0} \right) =? \\
	\end{gather}
$$
מקושי-שוורץ מתקיים
$$
	\left| \frac{ \partial f }{ \partial v } \left( x_{0},y_{0} \right)  \right| =\left| \left< \nabla f\left( x_{0},y_{0} \right) ,v \right>  \right| \leq \lVert \nabla f\left( x_{0},y_{0} \right)  \rVert\cdot \lVert v \rVert =\lVert \nabla f\left( x_{0},y_{0} \right)  \rVert  
$$
ויש שוויון אם ורק אם (ב$\leq$ האחרון) אם ורק אם הוקטור $v$ פרופורציונלי ל$\nabla f\left( x_{0},y_{0} \right)$, כלומר אם קיים $c\in \mathbb{R}$ כך ש $v=c\nabla f\left( x_{0},y_{0} \right)$
ואז מתקיים
$$
	\begin{gather}
	1=\lVert v \rVert = \left| c \right| \lVert \nabla f\left( x_{0},y_{0} \right)  \rVert \implies c =\pm \frac{1}{\lVert \nabla f\left( x_{0},y_{0} \right)  \rVert } \\
	\implies \text{The supremum is attained when } v= \frac{\nabla f\left( x_{0},y_{0} \right) }{\lVert \nabla f(x_{0},y_{0}) \rVert } \\
	\implies \text{For infimum it's when } v = - \frac{\nabla f\left( x_{0},y_{0} \right) }{\lVert \nabla f\left( x_{0},y_{0} \right)  \rVert } 
	\end{gather}
$$
ולכן
$$
	\sup_{\lVert v \rVert =1} \frac{ \partial f }{ \partial v } \left( x_{0},y_{0} \right) =\left< \delta f\left( x_{0},y_{0} \right) , \frac{\nabla f\left( x_{0},y_{0} \right) }{\lVert \nabla f\left( x_{0},y_{0} \right)  \rVert } \right> = \lVert \nabla f\left( x_{0},y_{0} \right)  \rVert 
$$
ועבור אינפימום זה $\lVert \nabla f\left( x_{0},y_{0} \right) \rVert-$
# טענה - דיפרנציאביליות גורר רציפות
אם $f$ דיפרנציאבילית ב-$f\left( x_{0},y_{0}, \right)$ אזי היא רציפה ב-$\left( x_{0},y_{0} \right)$
## הוכחה
$$
	\begin{gather}
	f\left( x_{0}+\Delta x,y_{0}+\Delta y \right) -f\left( x_{0},y_{0} \right) \\
	= \frac{ \partial f }{ \partial x } \left( x_{0},y_{0} \right) \Delta x + \frac{ \partial f }{ \partial y } \left( x_{0},y_{0} \right) \Delta y + \epsilon \left( \Delta x,\Delta y \right) \xrightarrow{ \Delta x,\Delta y \to 0 } 0
	\end{gather}
$$
# דוגמה
$$
	f\left( x,y \right) = \begin{cases}
	\frac{xy}{x^{2}+y^{2}} & \left( x,y \right) \neq \left( 0,0 \right)  \\
	0 & \left( x,y \right) =\left( 0,0 \right) 
	\end{cases}
$$
ניקח $\left( x_{0},y_{0} \right)=\left( 0,0 \right)$
$$
	\begin{gather}
	\frac{ \partial f }{ \partial x } \left( 0,0 \right) =0 \\
	\frac{ \partial f }{ \partial y } \left( 0,0 \right) =0
	\end{gather}
$$
$$
	f\left( x,\lambda x \right) = \frac{\lambda x^{2}}{x^{2}+\lambda^{2}x^{2}} = \frac{\lambda}{1+\lambda x}
$$
$$
	\lim_{ x \to 0 } f\left( x,\lambda x \right) = \frac{\lambda}{1+\lambda^{2}}
$$
