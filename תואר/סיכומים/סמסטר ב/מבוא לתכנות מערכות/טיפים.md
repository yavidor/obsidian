# דברים כלליים
- תקראו את כל השאלה לפני שאתם מתחילים לענות עליה, בגלל כמות הסעיפים זה מרגיש מעצבן אבל זה חשוב, לפעמים דרישה מסעיף ד' תשנה את הדרך שבה נחשוב על סעיף א'
-  בלי מספרי קסם, אם אתם רואים שאתם משתמשים במספר כלשהו שהוא לא $0$, עדיף להגדיר קבוע שייצג אותו
# CPP
- const correctness זה דבר שממש קל ליפול עליו, תוודאו שאתם יודעים תמיד מה המצב של המשתנים שלכם
- תזכרו מה נמצא ב`heap` ומה נמצא ב`stack`  כשאתם יוצרים משתנים, במיוחד אם מדובר במחלקות מסובכות
- תזכרו לעשות `std::move` כשאתם מעבירים `unique_ptr`
- כשאתם מקצים זיכרון תבדקו שהצלחתם, כדי שתדעו לשחרר דברים אחרים אם לא הצלחתם (ניסוח קצת עילג אבל אני לא יודע איך להסביר את זה אחרת, רלוונטים רק בקונסטרקטורים)
- תזכרו לעשות הורס וירטואלי למחלקות אב
# Python
- תוודאו שאתם יודעים איך להשתמש ב`sys.argv`, זה לא משהו מסובך אבל זה דרך מהירה לאבד נקודות (לדעת מה יש בו במקום האפס, איך לפנות לדברים עם שמות וכדומה)
- יש דברים שלא למדנו שכנראה מצופה שנכיר כי החיים מבאסים. תקראו שנייה איך ירושה עובדת בפייתון ואיך משתמשים בה
- אותו דבר לגבי מתודות קסם למיניהן (למרות שעל זה כן עברנו)
# Git
- תוודאו שאתם מכירים את המונחים השונים
- תלמדו את ההבדל בין ליצ'ור בראנץ' חדש לליצור קומיט חדש באותו הבראנץ', בין מרג' וריבייס, דברים כאלה.
