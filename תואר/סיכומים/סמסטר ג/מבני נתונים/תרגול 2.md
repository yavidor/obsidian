# דוגמה לחישוב רקורסיה
נסתכל על אלגוריתם למצוא אביר מקסימלי במערך לא ממוין
```cpp
int max (int h, int t) {
  if (h == t) return A[t];
  else {
    m = (h + t) / 2
    M1 = max(h,m-1);
    M2 = max(m,t)
    return (M1 > M2) ? M1 : M2;
}
```

## מהי סיבוכיות זמן הריצה?
נבנה משוואה רקורסיבית $T\left( n \right)$ אשר תתאר את זמן הריצה של האלגוריתם, כאשר $n$ מסמן את גודל המערך
$$
	T\left( n \right) =\begin{cases}
	c_{1} & n=1 \\
	2\cdot T\left( \frac{n}{2} \right) +c_{2} & n>1
	\end{cases}
$$
