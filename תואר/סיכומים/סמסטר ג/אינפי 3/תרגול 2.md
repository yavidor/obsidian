# הגדרת רענון - גזירות / דיפרנציאביליות
נאמר ש-$f:\mathbb{R}^{n}\to \mathbb{R}^{m}$ גזירה בנקודה $x \in \mathbb{R}^{n}$ אם קיימת פונקציה לינארית $L:\mathbb{R}^{n}\to \mathbb{R}^{m}$ כך ש
$$
	f\left( x+h \right) f\left( x \right) +L\left( h \right) +o\left( h \right) 
$$
(כאשר $o$ הוא אותו $o$ כמו ב-[[זמן ריצה]], כלומר $g=o\left( h \right)$ אם $\lim_{ h \to 0 } \frac{\lVert g\left( h \right) \rVert}{\lVert h \rVert}=0$)
# תרגיל ${1}$
נתבונן ב-$M_{n}\left( \mathbb{R} \right)$ עם הנורמה האוקלידית על $\mathbb{R}^{n^{2}}$ (כלומר $\lVert A \rVert=\sqrt{\sum_{i,j\in \left[ n \right]}a_{i,j}^{2}}$) מכונה גם נורמת פרובניוס.
בהינתן $A\in M_{n}\left( \mathbb{R} \right)$, מצאו את הנגזרת של הפונקציה
$$
	\begin{gather}
	f:M_{n}\left( \mathbb{R} \right) \to M_{n}\left( \mathbb{R} \right)  \\
	f\left( B \right) =B^{2}
	\end{gather}
$$
בנקודה $A$
## פתרון ${1}$
לפי הגדרה
$$
	f\left( A+H \right) =\left( A+H \right) ^{2}=\underbrace{ A^{2} }_{ f\left( A \right)} +\underbrace{ AH+HA }_{ L\left( H \right) ??? }+\underbrace{ H^{2} }_{ o\left( H \right) ??? } 
$$
נקווה (יותר בכיוון של ננחש) כי $H^{2}=o\left( H \right)$ ו $AH+HA=L\left( H \right)$ (כלומר שזה לינארי)
קל לראות כי $L\left( H \right)=AH+HA$ [[העתקה לינארית|לינארית]]
נראה כי $H^{2}=o\left( H \right)$
$$
	\frac{\lVert H^{2} \rVert }{\lVert H \rVert} \underset{ ? }{ \leq } \frac{\lVert H \rVert ^{2}}{\lVert H \rVert } = \lVert H \rVert \xrightarrow{ \lVert H \rVert \to 0 }0
$$
מסתבר שזה אי-שוויון ידוע עבור נורמת פרובניוס, אבל אנחנו לא מכירים את הנורמה הזו, אז כנראה נצטרך להוכיח זאת.
$$
	\begin{gather}
	
	\lVert B\cdot C \rVert ^{2}= \sum_{i,j\in \left[ n \right] } \left( \sum_{i\in \left[ k \right] }b_{i,k}\cdot c_{k,j} \right) ^{2}  \\
	\underset{ C-S }{ \leq  } \sum_{i,j\in \left[ n \right] } \left( \sum_{k\in \left[ n \right]}b_{i,k}^{2} \right)  \left( \sum_{k\in \left[ n \right]}b_{i,k}^{2} \right) = \lVert B \rVert^{2}\cdot \lVert C \rVert ^{2} 
	\end{gather}
$$
