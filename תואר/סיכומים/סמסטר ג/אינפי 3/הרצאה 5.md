# קיום מישור משיק לגרף של פונקציה דיפרנציאבילית $\mathbb{R}^{2}\to \mathbb{R}$
אומרים שמישור $T$ משיק למשטח $S$ בנקודה $P_{0}$ אם קיימת סביבה של $P_{0}$ (על $S$) כך שלכל נקודה $P$ בסביבה זו מתקיים שהזווית בין הווקטור $\overrightarrow{P_{0}P}$ לבין המישור $T$ שואפת לאפס כאשר $P\to P_{0}$, לחלופין - הזוית בין $\overrightarrow{P_{0}P}$ לבין הנורמל $\vec{N}$ למישור $T$ שואפת ל-$\frac{\pi}{2}$ כאשר $P\to P_{0}$
# מישור
תהי $f:\Omega \subseteq \mathbb{R}^{2}\to \mathbb{R}$ פוקנציה דיפרנציאבילית בנקודה $\left( x_{0},y_{0} \right)$. אזי המישור
$$
	T:z=f\left( x_{0},y_{0} \right) + \frac{ \partial f }{ \partial x } \left( x_{0},y_{0} \right) \left( x-x_{0} \right) + \frac{ \partial f }{ \partial y } \left( x_{0},y_{0} \right) \left( y-y_{0} \right) 
$$
משיק למשטח
$$
	S:z=f\left( x,y \right) 
$$
בנדוה
$$
	P_{0}=\left( x_{0},y_{0}fl(x_{0},y_{0}) \right) 
$$
בפרט: הוקטור $\vec{N}=\left( -\frac{ \partial f }{ \partial x }\left( x_{0},y_{0} \right),-\frac{ \partial f }{ \partial y }\left( x_{0},y_{0} \right),1 \right)$ ניצב למשטח בנקודה $P_{0}$.
## הוכחה
נשים לב שהמישור $T$ עובר בנקודה $P_{0}$, נראה שהווקטור $\vec{N}$ הוא הנורמל הדרוש
נמצא את הזווית
$$
	\cos\theta= \frac{\overrightarrow{P_{0}P}\cdot \vec{N}}{\lVert \overrightarrow{P_{0}P}  \rVert \lVert \vec{N} \rVert  }
$$
נראה כי $\displaystyle\lim_{P\to P_{0}}\cos\theta=0$
נתבונן במכנה
$$
	\begin{gather}
	P\left( x,y,f\left( x,y \right)  \right)  \\
	P_{0}=\left( x_{0},y_{0},f\left( x_{0},y_{0} \right)  \right) 
	\end{gather}
$$
$$
	\begin{gather}
	\overrightarrow{P_{0}P}=\vec{P}-\vec{P_{0}} = \left( x-x_{0},y-y_{0},f\left( x,y \right) -f\left( x_{0},y_{0} \right)  \right) 
	\end{gather}
$$
$$
	\begin{gather}
	\lVert \overrightarrow{P_{0}P} \rVert  = \sqrt{\left( x-x_{0} \right) ^{2}+\left( y-y_{0} \right) ^{2}+\left( f\left( x,y \right) -f\left( x_{0},y_{0} \right)  \right) ^{2}} \\
	\geq \sqrt{\left( x-x_{0} \right)^{2} + \left( y-y_{0} \right) ^{2} }
	\end{gather}
$$
$$
	\lVert \vec{N} \rVert  = \sqrt{\left( \frac{ \partial f }{ \partial x }  \right) ^{2}+ \left( \frac{ \partial f }{ \partial y }  \right) ^{2}+1} \geq 1
$$
וכעת
$$
	\begin{gather}
	0 \leq \left| \cos\theta \right| = \frac{\left| \overrightarrow{P_{0}P} \cdot \vec{N} \right| }{\lVert \overrightarrow{P_{0}P} \rVert \lVert \vec{N} \rVert  } \leq \frac{\left| \overrightarrow{P_{0}P}\cdot \vec{N} \right| }{\sqrt{\left( x-x_{0} \right) ^{2}+\left( y-y_{0} \right) ^{2}}} \\
	= \frac{\left| -\frac{ \partial f }{ \partial x } \left( x_{0},y_{0} \right) \left( x-x_{0} \right) - \frac{ \partial f }{ \partial y } \left( x_{0},y_{0} \right) \left( y-y_{0} \right)+f\left( x,y \right) -f\left( x_{0},y_{0} \right)   \right| }{\sqrt{\left( x-x_{0} \right) ^{2}+\left( y-y_{0} \right) ^{2}}} \\
\xrightarrow{ P\to P_{0} } 0
	\end{gather}
$$
השאיפה בסוף מגיעה מדיפרנציאביליות של $f$.
ומכאן על פי כלל הסנדוויץ'
$\blacksquare$
