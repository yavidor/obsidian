# כלל השרשרת
תהי $F:\Omega \subseteq \mathbb{R}^{n}\to \mathbb{R}^{m}$ ותהי $G:\phi \subseteq \mathbb{R}^{m}\to \mathbb{R}^{k}$
כך ש $F$ דיפרנציאבילית בנקודה פנימית $x \in\Omega$ ו-$G$ דיפרנציאבילית בנקודה פנימית $y\in \phi$ כך ש-$y=F\left( x \right)$.
אזי הפונקציה $G\circ F:\Omega \subseteq \mathbb{R}^{n}\to \mathbb{R}^{k}$ דיפרנציאבילית בנקודה $x$ ומתקיים 
$$
	D\left( G\circ F \right) |_{x}=DG|_{F\left( x \right) }DF|_{x}
$$
כאשר מצד ימין יש כפל מטריצות של מטריצה $k \times m$ במטריצה $m \times n$

> [!tip] מזכיר אינפי 1
> כן, כי זה מאוד דומה לכלל השרשרת מאינפי ${1}$
> 
> $$
> 	\left( g\left( f\left( x \right)  \right)  \right) ' = g'\left( f\left( x \right)  \right) f'\left( x \right) 
> $$

## הוכחה
הפונקציה $F$ דיפרנציאבילית בנקודה $x$, לכן נוכל לרשום
$$
	F\left( x+\Delta x \right) =F\left( x \right) +DF|_{x}\left( \Delta x \right) +R_{1}\left( \Delta x \right) 
$$
כאשר $R_{1}:\mathbb{R}^{n}\to \mathbb{R}^{m}$ ומתקיים
$$
\left( 1 \right) 	\begin{gathered}
	\lim_{ \lVert \Delta x \rVert  \to 0 } \frac{\lVert R_{1}\left( \Delta x \right)  \rVert }{\lVert \Delta x \rVert }=0
	\end{gathered}
$$
בנוסף, הפונקציה $G$ דיפרנציאבילית בנקודה $y$ ולכן
$$
	G\left( y+\Delta y \right) =G\left( y \right) +DG|_{y} + R_{2}\left( \Delta y \right) 
$$
כאשר $R_{2}:\mathbb{R}^{m}\to \mathbb{R}^{k}$ ומתקיים
$$
	\left( 2 \right) 	\begin{gathered}
	\lim_{ \lVert \Delta y \rVert  \to 0 } \frac{\lVert R_{2}\left( \Delta y \right)  \rVert }{\lVert \Delta y \rVert }=0
	\end{gathered}
$$
וכעת
$$
	\begin{gather}
	\left( G\circ F \right) \left( x+\Delta x \right) = G\left( F\left( x+\Delta x \right)  \right)  \\
	\underset{ F\text{ is differentiable} }{ = } G\left( \underbrace{ F\left( x \right) }_{ y }+\underbrace{ DF|_{x}\left( \Delta x \right) +R_{1}\left( \Delta x \right)  }_{ \Delta y }   \right)  \\
	= G\left( y+\Delta y \right) \underset{ G\text{ is differentiable} }{ = } G\left( y \right) +DG|_{y}\left( \Delta y \right) +R_{2}\left( \Delta y \right)  \\
	=G\left( F\left( x \right) +DG|_{y}\left( DF|_{x}\left( \Delta x \right) +R_{1}\left( \Delta x \right)  \right)  \right) +R_{2}\left( \Delta y \right)  \\
	= \left( G\circ F \right) \left( x \right) +\left( DG|_{F\left( x \right)}  DF|_{x}\left( \Delta x \right)  \right) +\underbrace{ DG|_{y}\left( R_{1}\left( \Delta x \right)  \right) +R_{2}\left( \Delta y \right) }_{ R_{3} } 
	\end{gather}
$$
אם נראה כי $\displaystyle\lim_{ \lVert \Delta x \rVert \to 0 } \frac{\lVert R_{3}\left( \ldots \right) \rVert}{\lVert \Delta x \rVert}$ אז גמרנו
באמצעות אי שוויון המשולש נעשה
$$
	\lVert R_{3} \rVert \leq \lVert DG|_{F\left( x \right) }\left( R_{1}\left( \Delta x \right)  \right)  \rVert +\lVert R_{2}\left( \Delta y \right)  \rVert 
$$
ונראה שכל אחד מהחוברים הנ"ל, לאחר חלוקה ב$\lVert \Delta x \rVert$ מקיים $\lim_{ \lVert x \rVert \to 0 }\ldots=0$
### המחובר הראשון
צריך לזכור כי $DG|_{F\left( x \right)}$ הוא [[העתקה לינארית]], לכן הוא מיוצג ע"י [[מטריצה]], ולכן קיים קבוע $M_{G}$ כך ש
$$
	\lVert DG|_{F\left( x \right) } \left( R_{1}\Delta x \right)  \rVert \leq M_{G}\lVert R_{1}\left( \Delta x \right)  \rVert 
$$

> [!HINT] למה זה נכון
> זה לפי ה[[תואר/סיכומים/סמסטר ג/אינפי 3/הרצאה 1#דוגמה שהיא גם טענה|דוגמה בהרצאה 1]]

נחלק את שני הצדדים ב-$\lVert \Delta x \rVert$ ונקבל כי
$$
	0\leq \frac{\lVert DG|_{F\left( x \right) }\left( R_{1}\left( \Delta x \right)  \right)  \rVert }{\lVert \Delta x \rVert }\leq M_{G} \frac{\lVert R_{1}\left( \Delta x \right)  \rVert }{\lVert \Delta x \rVert } \to 0
$$
כאשר הצד הימני שואף לאפס בגלל $\left( 1 \right)$ (למעלה) ובגלל ש-$M_{G}$ הוא קבוע
ולכן, מסנדוויץ' הביטוי כולו שואף לאפס
### המחובר השני
אנו רוצים לחשב 
$$
	\lim_{ \lVert \Delta x \rVert  \to 0 } \frac{\lVert R_{2}\left( \Delta y \right)  \rVert }{\lVert \Delta x \rVert }
$$
(צ"ל גבול שווה ל-${0}$), אבל מה שידוע מ $\left( 2 \right)$ זה $\displaystyle\lim_{ \lVert \Delta y \rVert \to 0 } \frac{\lVert R_{2}\left( \Delta y \right) \rVert}{\lVert \Delta y \rVert}$
נרחיב על פי איך שהגדרנו את $\Delta y$
$$
	\lVert \Delta y \rVert = \lVert DF|_{x}\left( \Delta x \right) +R_{1}\left( \Delta x \right)  \rVert \underset{ \triangle }{ \leq } \lVert DF|_{x}\left( \Delta x \right)  \rVert +\lVert R_{1}\left( \Delta x \right)  \rVert 
$$
כמו קודם, נשתמש בחסם שיש לנו מהיות $DF|_{x}$ העתקה לינארית, נסמנו $M_{F}$ (בלי דום, פשוט $M_{F}$)
וכעת
$$
\lVert DF|_{x}\left( \Delta x \right)  \rVert +\lVert R_{1}\left( \Delta x \right)  \rVert  \leq M_{F}\lVert \Delta x \rVert + \frac{\lVert R_{1}\left( \Delta x \right)  \rVert }{\lVert \Delta x \rVert }\lVert \Delta x \rVert 
$$
נסכם (ונסמן)
$$
	\left( 4 \right) \lVert \Delta y \rVert \leq \left( M_{F}+ \frac{\lVert R_{1}\left( \Delta x \right)  \rVert }{\lVert \Delta x \rVert } \right) \lVert \Delta x \rVert 
$$
ונזכר שאנחנו רוצים להוכיח כי
$$
	\lim_{ \lVert \Delta x \rVert  \to 0 } \frac{\lVert R_{2}\left( \Delta y \right)  \rVert }{\lVert \Delta x \rVert }=0
$$
כלומר שלכל $\varepsilon>0$ קיים $\delta \left( \varepsilon \right)>0$ כך ש
$$
	\lVert \Delta x \rVert <\delta\implies \frac{\lVert R_{2}\left( \Delta y \right)  \rVert }{\lVert \Delta x \rVert } > \varepsilon
$$
אז יאללה, יהי $\varepsilon>0$
מ-$\left( 1 \right)$ נובע שעבור אותו $\varepsilon$ קיים $\delta$ כך ש
$$
	\left( I \right) \lVert \Delta x \rVert <\delta\implies \frac{\lVert R_{1}\left( \Delta x \right)  \rVert }{\lVert \Delta x \rVert } < \varepsilon
$$
במידה דומה, מ-$2$ נובע כי לכל $\tilde{\varepsilon}>0$ קיימת $\tilde{\delta}>0$ כך ש
$$
	\left( II \right) \lVert \Delta y \rVert <\tilde{\delta}\implies \frac{\lVert R_{2}\left( \Delta y \right)  \rVert }{\lVert \Delta y \rVert }<\tilde{\varepsilon} 
$$
ועתה
$$
	\begin{gather}
	
	\lVert R_{2}\left( \Delta y \right)  \rVert < \lVert \Delta y \rVert \tilde{\varepsilon} \underset{ \left( 4 \right)  }{ \leq } \tilde{\varepsilon} \left( M_{F} + \underbrace{ \frac{\lVert R_{1}\left( \Delta x \right)  \rVert }{\lVert \Delta x \rVert } }_{ I,<\varepsilon } \right) \lVert \Delta x \rVert  \\
	< \tilde{\varepsilon}\left( M_{F}+\varepsilon \right) \lVert \Delta x \rVert 
	\end{gather}
$$
בהינתן $\varepsilon$, נבחר $\delta$ כך שיתקיים $I$, ועבור $\varepsilon$ הנ"ל נוכל לבחור $\tilde{\varepsilon}= \frac{\varepsilon}{M_{F}+\varepsilon}$ ואז עבור $\tilde{\varepsilon}$ זה, נבחר $\tilde{\delta}$ כך שיתקיים $II$, ואז
$$
	\frac{\lVert R_{2}\left( \Delta y \right)  \rVert }{\lVert \Delta x \rVert } <\varepsilon
$$
$\blacksquare$
# תזכורת
אם $F$ העתקה לינארית, אז $DF|_{x}=F$ (ראינו את זה ב[[הרצאה 3]])
אם $F$ העתקה אפינית (כלומר $F=Ax+B$) אז $DF|_{x}=A$

$$
\left\{ x \in \mathbb{R}^{n}: x=a+t\left( b-a \right) ,0\leq t \leq 1 \right\}

## משפט הערך הממוצע
תהי $f:\Omega \subseteq \mathbb{R}^{n}\to \mathbb{R}$ כאשר $\Omega$ קבוצה קמורה כך ש-$f$ דיפ' בכל נקודה פנימית $x \in\Omega$ ותהיינה $a,b$ נקודות פנימיות ב-$\Omega$.
אזי קיימת נקודה $c\in\Omega$ אחת לפחות על הקטע הישר שמחבר את $a$ ל-$b$. כך ש
$$
	f\left( b \right) -f\left( a \right) =DF|c\left( b-a \right) 
$$
