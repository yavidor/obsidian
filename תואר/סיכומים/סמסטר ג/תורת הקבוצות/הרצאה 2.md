# General Prob. Spaces
What about choosing a number "uniformly" in $\left[ 0,1 \right]$?
We expect for example to have
$$
	\begin{gather}
	\mathbb{P}\left( \left[ 0, \frac{1}{2} \right]  \right) = \frac{1}{2} \\
	\mathbb{P}\left( \left[ 0.2,0.6 \right]  \right) = \frac{4}{10}=0.4 \\
	\mathbb{P}\left( \left\{ 0.7 \right\}  \right) =p\left( 0.7 \right) =0
	\end{gather}
$$
Well, the last one is the problem, the probability for a specific one is ${0}$, not "practically ${0}$" actual ${0}$.
So we need to find a way to handle the continuity
# Definition - Attempt \#1
A prob. space is a pair $\left( \Omega,\mathbb{P} \right)$ where
- $\Omega$ is *any* set, called "sample space"
- $\mathbb{P}:2^{\Omega}\to \left[ 0,1 \right]$ such that
	-  $\mathbb{P}\left( \Omega \right)=1$
	- For every $\left( A_{n} \right)_{n=1}^\infty \subseteq\Omega$ such that $(\forall m\neq n)\left( A_{n}\cap A_{m}=\emptyset \right)$ we have 
	  $$
	  	\mathbb{P}\left( \bigcup_{n=1}^\infty A_{n}\right)= \sum_{n=1}^{\infty}  \mathbb{P}\left( A_{n} \right)  
	  $$

Note that with this definition we are ok with the following
$$
	\mathbb{P}\left( \left[ 0, \frac{1}{2} \right]  \right) \neq \sum_{\omega \in \left[ 0, \frac{1}{2} \right] } \mathbb{P}\left( \underbrace{ \left\{ \omega \right\} }_{ 0 }  \right) 
$$
And yes, the right hand side is a bit of mess
