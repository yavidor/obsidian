# Question ${4}$
```cpp
int arr[6] = {3,1,4,1,5,9}
```
Start at memory address `0xBFFFFF00`
Register `s0` contains `arr`'s  address, and integers are ${4}$ bytes
Let's see what the next snippet does
```arm-asm
lw t0, 0(s0) #Loads arr[0] ino register t0
lw t1, 8(s0) #Loads arr[2] into register t1
add t2, t0, t1 #Sets t2 equal to t0 plus t1
sw t2, 4(s0) # Sets arr[1] equal to value in t2
```
So in c is is basically
```c
arr[1] = arr[0] + arr[2]
```
