We are still talking about [[Random Variables#Continuous random variables|Continuous random variables]]
# Example
Let $X$ be a random variable with density
$$
	f_{X}\left( y \right) = \begin{cases}
	c\left( 2y-y^{2} \right)  & 0\leq y\leq 2 \\
	0 & otherwise
	\end{cases}
$$
For some constant $c> 0$.
What is $\mathbb{P}\left( \frac{1}{2} \leq X \leq \frac{3}{2} \right)$?
We have 
$$
	1 = \int_{-\infty}^{\infty} f_{X}= c \int_{0}^{2} \left( 2y-y^{2} \right)= c \cdot \left( y^{2}-\frac{y^{3}}{3}\bigg|^2  _{0}\right) = \frac{4}{3}c \implies c=\frac{3}{4}
$$
Therefore
$$
\mathbb{P}\left( \frac{1}{2 }\leq X\leq \frac{3}{2} \right) = \int_{\frac{1}{2}}^{\frac{2}{3}} f_{X} =  \int_{\frac{1}{2}}^{\frac{2}{3}}  \frac{3}{4}\left( 2y-y^{2} \right) = \ldots = \frac{11}{16}
$$
# Example
Take a block of uranium. It has $n$ elements ($n$ is huge).
Every second, every electron has prob. $p$ to decay.
In $t$ seconds each electron has prob $\approx$ $t\cdot p$ to decay.
Let $X_{t}$ be the number of electrons that decayed in the first $t$ seconds.
$$
	X_{t} \sim Bin\left( n,t\cdot p \right)  \approx Poi\left( t \cdot \underbrace{ n \cdot p }_{ \lambda }  \right)  = Poi\left( \lambda t \right) 
$$
Let $T$ be the time until the first decay.
$$
	\mathbb{P}\left( T>t \right)= \mathbb{P}\left( X_{t}=0 \right) = \frac{e^{ -\lambda t }\left( \lambda t \right) ^{0}}{0!} = e^{ -\lambda t }
$$
So $T \sim Exp\left( \lambda \right)$
