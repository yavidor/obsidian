# Example of conditional probability
Assume $0.1\%$ of the population has COVID-19.
Assume a test for COVID is $99\%$ (in both direction).
I get tested and test positive, what's the prob. I have COVID?
## Answer
Let's define our events
$$
	\begin{gather}
	A="\text{I have covid}" \\
	B="\text{I tested positive}"
	\end{gather}
$$
Since only $0.1\%$ has COVID we have $\mathbb{P}\left( A \right)=0.001$
And since the test is $99\%$ accurate we also have $\mathbb{P}\left( B|A \right)=0.99,\mathbb{P}\left( B|A^{c} \right)=0.01$
Therefore, by Bayes' theorem we have
$$
	\mathbb{P}\left( A|B \right) = \frac{\mathbb{P}\left( B|A \right) \mathbb{P}\left( A \right) }{\mathbb{P}\left( B \right) }
$$
We can calculate $\mathbb{P}\left( B \right)$ using the law of total prob. and get that
$$
	\mathbb{P}\left( B \right) = \mathbb{P}\left( B|A \right) \mathbb{P}\left( A \right) +\mathbb{P}\left( B|A^{c} \right)\mathbb{P}\left( A^{c} \right)  
$$
And now
$$
	\begin{gather}
	\mathbb{P}\left( A|B \right) = \frac{\mathbb{P}\left( B|A \right) \mathbb{P}\left( A \right) }{\mathbb{P}\left( B|A \right) \mathbb{P}\left( A \right) +\mathbb{P}\left( B|A^{c} \right) \mathbb{P}\left( A^{c} \right) } \\
	= \frac{0.99 \cdot 0.001}{0.09 \cdot 0.001 + 0.01 \cdot 0.999} \approx 0.09 = 9\%
	\end{gather}
$$
# Proposition
Let $\left( \Omega,\mathcal{F},\mathbb{P} \right)$ be a [[General Probability Space|Prob. Space]]. Fix $B\in \mathcal{F}$ with $\mathbb{P}\left( B \right)>0$.
define 
$$
	\begin{gather}
	\hat{\mathbb{P}} : \mathcal{F}\to \left[ 0,1 \right]  \\
	\hat{\mathbb{P}}\left( A \right) =\mathbb{P}\left( A|B \right) 
	\end{gather}
$$
Then $\left( \Omega,\mathcal{F},\hat{\mathbb{P}} \right)$ is also a prob. space.
So for example
$$
	\mathbb{P}\left( \bigcup_{n=1}^\infty A_{n}|B \right) \leq \sum_{n=1}^{\infty}  \mathbb{P}\left( A_{n}|B \right)  
$$
(this is just [[General Probability Space#Sub-additivity| Sub-additivity]])
## Proof
We need to prove that $\left( \Omega,\mathcal{F},\hat{\mathbb{P}} \right)$ is a probability space, let's prove that it fits the properties (axioms?) of a prob. space
### $\hat{\mathbb{P}}\left( \Omega \right)=1$
$$
	\hat{\mathbb{P}}\left( \Omega \right) =\mathbb{P}\left( \Omega|B \right) = \frac{\overbrace{ \mathbb{P}\left( \Omega \cap B \right)  }^{ B }}{\mathbb{P}\left( B \right) }= 1
$$
## $\sigma$ additivity
We need to prove that If $\left( A_n \right)_{n=1}^{\infty}\subseteq \mathcal{F}$ such that $A_{n}\cap A_{m}=\emptyset,\forall n\neq m$ then $\hat{\mathbb{P}}\left( \bigcup_{n=1}^\infty A_{n}\right)=\sum_{n=1}^{\infty}\hat{\mathbb{P}}\left( A_{n} \right)$
$$
	\begin{gather}
	\hat{\mathbb{P}}\left( \bigcup_{n=1}^{\infty}A_{n} \right) =\mathbb{P}\left( \left( \bigcup_{n=1}^\infty A_{n} \right) \bigg|B \right)  \\
	= \frac{\mathbb{P}\left( \left( \displaystyle\bigcup_{n=1}^{\infty}A_{n} \right) \cap B \right) }{\mathbb{P}\left( B \right) }= \frac{\mathbb{P}\left( \displaystyle\bigcup_{n=1}^\infty \left( A_{n}\cap B \right)  \right) }{\mathbb{P}\left( B \right) } \\
	\underset{ \left( * \right)  }{ = } \frac{\displaystyle\sum_{n=}^{\infty} \mathbb{P}\left( A_{n}\cap B \right)   }{\mathbb{P}\left( B \right) } = \sum_{n=1}^{\infty}  \frac{\mathbb{P}\left( A_{n}\cap B \right) }{\mathbb{P}\left( B \right) } = \sum_{n=1}^{\infty}  \mathbb{P}\left( A_{n}|B \right)  \\
	= \sum_{n=1}^{\infty}  \hat{\mathbb{P}}\left( A_{n} \right) 
	\end{gather}
$$
$\left( * \right)$ since $\mathbb{P}$ is a prob function and $\left( A_{n}\cap B \right)_{n=1}^\infty$ are disjoint (from the condition that we assumed)
$\blacksquare$
# Independence
Let $\left( \Omega,\mathcal{F},\mathbb{P} \right)$ be a prob space and let $A,B\in \mathcal{F}$.
$A,B$ are <u>independent</u> if $\mathbb{P}\left( A\cap B \right)=\mathbb{P}\left( A \right)\mathbb{P}\left( B \right)$
If e.g $\mathbb{P}\left( B \right)>0$, this is the same as
$$
	\mathbb{P}\left( A|B \right)  = \frac{\mathbb{P}\left( A\cap B \right) }{\mathbb{P}\left( B \right) } = \mathbb{P}\left( A \right) 
$$
(And this is symmetric for $A$ and $B$)
