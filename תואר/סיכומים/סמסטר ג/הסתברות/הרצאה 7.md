# Examples
## A
We say a random variable $X$ is binomial with parameters $n\in \mathbb{N}$ and $0\leq q\leq 1$
if $\mathbb{P}\left( X\in \left\{ 0,1,2,\ldots,n \right\} \right)=1$ and 
$$
	p_{X}\left( k \right) =\binom{n}{k}q^{k}\left( 1-q \right) ^{n-k},0\leq k\leq n
$$
$X$ counts the number of "successes" in $n$ *independent* trials, where the prob. of success in each one is $q$.
## B
$X$ $i$$s$ <u>geometric</u> with parameter $0<q<1$ if
$$
	\mathbb{P}\left( X\in \left\{ 1,2,3,\ldots \right\}  \right) = 1
$$
And
$$
p_{X}\left( k \right)=\left( 1-q \right)^{k-1}q
$$
$X$ is the total number of *independent* trial until the first success.
# Question
Flip a fair coin ${2n}$ times. Let $p_{n}$ be the prob to get exactly $n$ heads.
What is $\lim_{ n \to \infty }p_{n}$?
#### Answer
Let $X_{k}\sim Bin\left( 2n, \frac{1}{2} \right)$ (The $\sim$ does not mean approximation, it means that it goes $b$$y$ said distribution).
So 
$$
	p_{n} = \mathbb{P}\left( X_{n}=n \right) = \binom{2n}{n}  \left( \frac{1}{2} \right) ^{n} \left( \frac{1}{2} \right) ^{2n-n} = \binom{2n}{n} \frac{1}{4^{n}} = \frac{\left( 2n \right) !}{\left( n! \right) ^{2}} \cdot \frac{1}{4^{n}}
$$
Let's use $n!\approx \sqrt{2\pi n} \binom{n}{e}^{n}$ (STIRLING MENTIONED)
so
$$
	\begin{gather}
	
	p_{n}\approx \frac{\sqrt{2\pi \cdot2n} \binom{2n}{e} ^{2n}}{\left(\sqrt{2\pi n} \binom{n}{e}^{n}\right)^{2}} \cdot \frac{1}{4^{n}}= \frac{\sqrt{4\pi n}}{2\pi n}= \frac{1}{\sqrt{\pi n}} \xrightarrow{ n\to \infty } 0
	\end{gather}
$$
So since it goes by the same "rate" as this monster and the monster goes to ${0}$, $p_{n} \xrightarrow{ n\to \infty }0$

$$

$$

# Example
We say $X$ has a Poisson [[Distribution]] with parameter $\lambda>0$ if
$$
	\mathbb{P}\left( X\in \left\{ 0,1,2,\ldots \right\}  \right) =1
$$
and
$$
	p_{X}\left( k \right) = \frac{e^{ -\lambda }\lambda^{k}}{k!}
$$
Note 
$$
	\sum_{k=0}^{\infty}   p_{X}\left( k \right) = \sum_{k=0}^{\infty}  \frac{e^{ -\lambda } \lambda^{k}}{k!}= \frac{1}{e^{ \lambda }} \sum_{k=0}^{\infty}  \frac{\lambda^{k}}{k!}
$$
We got the [[טור טיילור|Taylor Series]] of [[קבוע אוילר|e^x]], so
$$
	= \frac{1}{e^{ \lambda }} \cdot e^{ \lambda }= 1
$$
## Claim
Fix $\lambda>0$, Assume $X\sim Poi\left( \lambda \right)$
And take $Y_{n}\sim Bin\left( n, \frac{\lambda}{n} \right)$
Then we have
$$
\forall k\in \left\{ 0,1,\ldots \right\} .	\lim_{ n \to \infty }  \mathbb{P}\left( Y_{n}=k \right) =\mathbb{P}\left( X_{n}=k \right) 
$$
### Proof
$$
\begin{gather}
\lim_{ n \to \infty } P\left( Y_{n}=k \right) =\lim_{ n \to \infty } \binom{n}{k} \left( \frac{\lambda}{n} \right) ^{k}\left( 1- \frac{\lambda}{n} \right) ^{n-k} \\
= \lim_{ n \to \infty }  \frac{n!}{k!\left( n-k! \right) }  \left( \frac{\lambda}{n} \right) ^{k}\left( 1- \frac{\lambda}{n} \right) ^{n-k}  \\
= \lim_{ n \to \infty } \frac{\lambda^{k}}{k!} \frac{\left( n-k+1 \right) \left( n-k+2 \right)\cdots n}{n^{k}} \left( 1-\frac{\lambda}{n} \right) ^{n}\left( 1- \frac{\lambda}{n} \right) ^{-k}   \\
=\frac{\lambda^{k}}{k!}\lim_{ n \to \infty } \frac{\text{Some polynomial of degree }k}{n^{k}}\left( 1-\frac{\lambda}{n} \right) ^{n}\left( 1- \frac{\lambda}{n} \right) ^{-k}  
\end{gather}
$$
As we know from #אינפי/אינפי1 when we look at the limit of a quotient of two [[פולינום|polynomial]] with the same degree, we care only about the leading coefficient, here it's $\frac{1}{1}=1$.
Note that $\left( 1-\frac{\lambda}{n} \right)^{n}$ is a variation of the limit that defined [[קבוע אוילר|e]]. and such
$$
	= \frac{\lambda^{k}}{k!} \cdot 1 \cdot e^{ -\lambda } \cdot 1 ^{-k} = \frac{e^{ -\lambda }\lambda^{k}}{k!} = \mathbb{P}\left( X=k \right) 
$$
