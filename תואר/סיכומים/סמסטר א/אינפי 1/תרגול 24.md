# משפט לגרנז'

> [!TODO] להשוות
> לערך [[משפט לגרנז']]

תהא $f$ [[רציפות]] ב-$\left[ a,b \right]$ ו[[נגזרת|גזירה]] ב-$\left( a,b \right)$
קיימת $c\in \left( a,b \right)$ כך ש:
$$
f'\left( c \right) = \frac{f\left( b \right) -f\left( a \right) }{b-a}
$$
## מסקנות
$\forall x \in \left( a,b \right):f'=0$ $\impliedby$ $f$ קבועה
$\forall x \in \left( a,b \right):f'\geq 0$ $\impliedby$ $f$ מונוטונית עולה
$\forall x \in:\left( a,b \right): f>0$ $\implies$ מונוטונית עולה ממש
# תרגיל 1
תהא $f$ גזירה פעמיים ב-$\left( 0,\infty \right)$. $f''>0$. בנוסף $\lim_{ x \to \infty }f\left( x \right)=L$ סופי
### א
הוכיחו כי $\lim_{ x \to \infty }f'\left( x \right)$ קיים במובן הרחב
### ב
הוכיחו כי קיימת סדרה $a_{n}\to \infty$ כך ש$\lim_{ n \to \infty }f'\left( a_{n} \right)=0$
### ג
הוכיחו כי $f'\left( x \right)<0$ לכל $x>0$
### ד
הוכיחו כי $f\left( x \right)>L$  לכל $x>0$
## דוגמה לפונקציה המקיימת את התנאי
$$
\begin{gather}
f\left( x \right) =\frac{1}{x} \\
f''\left( x \right) = \frac{2}{x^{3}}>0 \\
\lim_{ x \to \infty } f\left( x \right) =0
\end{gather}
$$

## פתרון 1
### א
$f''>0$ ולכן כמסקנה מלגרנז', $f'$ מונוטונית עולה ממש. ממשפט, הגבולות ב$\pm \infty$ של פונקציה מונוטונית קיימים במובן הרחב ולכן הגבול $\lim_{ x \to \infty }f'\left( x \right)$ קיים במובן הרחב.
### ב
לכל $n\in \mathbb{N}$, נתבונן בקטע $\left[ n,n+1 \right]$, $f$ רציפה וגזירה בקט זה, ולכן מלגרנז' קיימת $n<c_{n}<n+1$ כך ש:
$$
f'\left( c_{n} \right) = \frac{f\left( n+1 \right) -f\left( n \right) }{\left( n+1 \right) -n}=f\left( n+1 \right) -f\left( n \right) 
$$
$f\left( x \right)\xrightarrow{ x\to \infty }L \implies f\left( n \right),f\left( n+1 \right)\to L$ לפי היינה. ולכן
$f'\left( c_{n} \right)=f\left( n+1 \right)-f\left( n \right)\to L-L=0$ לפי אריתמטיקה של חיסור
$c_{n}>n$ לכל $n$, ולכן מכלל הפיצה $c_{n}\to \infty$
### ג
לפי א', $\lim_{ x \to \infty }f'\left( x \right)$ קיים. ולכן מהיינה עבור כל סדרה $x_{n}\to \infty$ מתקיים
$$
\lim_{ n \to \infty } f'\left( x_{n} \right) =\lim_{ x \to \infty } f'\left( x \right) 
$$
בסעיף ב' מצאנו סדרה $c_{n}\to \infty$ כך ש $f'\left( c_{n} \right)\to 0$ ולכן
$$
\lim_{ x \to \infty } f'\left( x \right) =0
$$
לפי א', $f'$ מונוטונית עולה. לכן $\sup\left\{ f'\left( x \right) \right\}=\lim_{ x \to \infty }f'\left( x \right)$ ולכן לכל $x>0$ מתקיים $f'\left( x \right)\leq 0$
אם קיים $x_{0}$ כך ש$f'\left( x_{0} \right)=0$, נקבל שלכל $x_{0}<x$ מתקיים $0=f'\left( x_{0} \right)<f\left( x \right)\leq 0$, סתירה. לכן $f'\left( x \right)<0$
### ד
$f'<0$ אומר ש$f$ יורדת ממש וזה אומר ש $\lim_{ x \to \infty }f\left( x \right)=\inf\left\{ f\left( x \right) \right\}$, נתון לנו שהגבול הזה הוא $L$
ולכן $L\leq f\left( x \right)$
ובאותה דרך שהשתמשנו בסעיף ג' ניתן להסיק גם פה ש$L<f\left( x \right)$ אבל אין כוח אז ממשיכים הלאה
# תרגיל 2
הוכיחו הפריכו
### א
$\lim_{ x \to a^{+} }f'\left( x \right)$ קיים $\impliedby$ $f'_{+}\left( a \right)$ (הנגזרת מימין) קיים
## פתרון 2
### א
לא נכון! דוגמה נגדית
$$
\begin{gather}
f=\left( x \right) \begin{cases}
x & x>0 \\
1 & x\leq0
\end{cases} \\
f'\left( x \right) = \begin{cases}
1 & x>0 \\
0 & x<0
\end{cases}
\end{gather}
$$
$\lim_{ x \to 0^{+} }f'\left( x \right)=1$
אבל $f'_{+}\left( 0 \right)$ לא קיים! כי $f$ לא רציפה מימין ב$x=0$

# תרגיל 3
תהי $f$ רציפה ב-$\left[ a,b \right]$, וגזירה בקטע $\left( a,b \right)$. הוכיחו
אם $\lim_{ x \to a^{+} }f'\left( x \right)$ קיים, אזי $f'_{+}\left( a \right)$ קיים, והם שווים.
## פתרון 3
לכל $a<x<b$, נתבונן בקטע $\left[ a,x \right]$, $f$ מקיימת בקטע זה את תנאי משפט לגרנז'
לכן קיימת $a<c_{x}<b$ כך ש:
$$
f'\left( c_{x} \right) = \frac{f\left( x \right) -f\left( a \right) }{x-a}~~~~~\left( * \right) 
$$
נגדיר
$$
c\left( x \right) =c_{x}
$$
$$
\lim_{ x \to a^{+} } c\left( x \right) =a
$$
לפי כלל הסנדוויץ' כי $a<c_{x}<x$
$\lim_{ x \to a^{+} } f'\left( x \right)=L$ קיים וגם $\lim_{ x \to a^{+} }c\left( x \right)=a$
לכן לפי הרבה של גבולות
$$
\lim_{ x \to a^{+} } f'\left( c\left( x \right)  \right) =L ~~~~\left( ** \right) 
$$
$$
f_{+}'\left( a \right) = \lim_{ x \to a^{+} }  \frac{f\left( x \right) -f\left( a \right) }{x-a} \underset{ \left( * \right)  }{ = } \lim_{ x \to a^{+} } f'\left( c_{x} \right) \underset{ \left( ** \right)  }{ = }L
$$

## מסקנה
לפונקציית הנגזרת יכולה להיות רק אי-רציפות עיקרית
# תרגיל 4
תהי $f$ רציפה ב-$\left[ 0,a \right]$
וגזירה בקטע $\left( 0,a \right]$. בנוסף $f\left( 0 \right)=0$, $f\left( a \right)\cdot f'f\left( a \right)<0$
הוכיחו:
קיימת $0<c<a$ כך ש$f'\left( c \right)=0$
## פתרון 4
$f\left( a \right)\cdot f'\left( a \right)<0$ ולכן $f\left( a \right),f'\left( a \right)$ בסימנים הפוכים.
נחלק למקרים
אם $f'\left( a \right)<0<f\left( a \right)$
$f$ רציפה בקטע $\left[ 0,a \right]$ וגזירה בקטע $\left( a,b \right)$ ולכן מלגרנז, קיימת $0<b<a$ כך ש
$$
f'\left( b \right) = \frac{f\left( a \right) -f\left( 0 \right) }{a-0}=\frac{f\left( a \right) -0 }{a}= \frac{f\left( a \right) }{a}\underset{ f\left( a \right) >0\land a >0 }{ > }0
$$
לכן $f_{-}'\left( a \right)<0<f_{+}'\left( b \right)$ כך ש:$f'\left( c \right)=0$
אם $f'\left( a \right)>0>f\left( a \right)$ מוכיחים באופן דומה
# תרגיל 5
האם הפונקציות הבאות הן נגזרת של פונקציה כשלהי
$$
\begin{gather}

f\left( x \right) = \begin{cases}
\frac{1-\cos x}{x^{2}} & x\neq 0 \\
1 & x =0
\end{cases} \\
g \left( x \right) = \begin{cases}
2x\sin \frac{1}{x}-\cos \frac{1}{x} & x \neq 0 \\
0 & x=0
\end{cases}
\end{gather}
$$
## פתרון 5
נבדוק רציפות ב$x=0$
$$
\begin{gather}
\lim_{ x \to 0 } f\left( x \right)  \\
=\lim_{ x \to 0 } \frac{1-\cos \left( x \right) }{x^{2}} \\
= \lim_{ x \to 0 } \frac{1-\cos ^{2}x}{x^{2}\left( 1+\cos x \right) }= \underset{ \to1 }{ \frac{\sin ^{2}x}{x^{2}} } \underset{ \to \frac{1}{2} }{ \frac{1}{\left( 1+\cos x \right) } } = \frac{1}{2}\neq 1
\end{gather}
$$
ל-$f$ אי רציפות סליקה, ולכן כמסקנה מדרבו, איננה נגזרת
$\lim_{ x \to 0 }g\left( x \right)$ לא קיים, ולכן $g$ לא רציפה ב$x=0$ מסוג עיקרית, זה עדיין לא אומר לנו האם היא נגזרת.
נזכר בפונקציה מלפני כמה תרגולים
$$
f_{2}\left( x \right) =\begin{cases}
x^{2}\sin \frac{1}{x} & x\neq 0 \\
0 & x=0
\end{cases}
$$
גזרנו אותה והנגזרת שלה הייתה זהה ל$g\left( x \right)$
אם לא היינו זוכרים, היינו בבעיה
# לופיטל
## לופיטל מסוג "$\frac{0}{0}$"
יהיו $f,g$ מוגדרות בסביבה מנוקבת של $x_{0}$ וגזירות שם. נניח:
א. $f\left( x \right),g\left( x \right)\to 0$
ב. $g'\left( x \right)\neq 0$ לכל $x$ בסביבה של $x_{0}$
ג. $\lim_{ x \to x_{0} } \frac{f'\left( x \right)}{g'\left( x \right)}=L$
אזי $\lim_{ x \to x_{0} } \frac{f\left( x \right)}{g\left( x \right)}$ קיים ושווה ל-$L$
יש גם ל $\frac{-\infty}{-\infty}, \frac{\infty}{\infty}$ וכו'

# תרגיל משהו
חשבו את הגבולות הבאים
### א
$$
\lim_{ x \to 0 } \left( 1+x \right)^{\frac{1}{\sin x}}
$$
## פתרון
### א
$$
\left( 1+x \right) ^{\frac{1}{\sin x}} = e^{ \ln \left( \left( 1+x \right)^{\frac{1}{\sin x}} \right)  }=e^{ \frac{\ln \left( 1+x \right) }{\sin x} }
$$
$$
\lim_{ x \to 0 } \frac{\ln \left( 1+x \right) }{\sin x}
$$
זה לופיטל "$\frac{0}{0}$", זה נכון רק אם קיים הגבול של הנגזרות
$$
\lim_{ x \to 0 } \frac{\frac{1}{1+x}}{\cos x}\to \frac{1}{1}=1
$$
$e^{ x }$ רציפה ב-$\mathbb{R}$, בפרט ב-$0$ ולכן
$$
\lim_{ x \to 0 } e^{ \left( \frac{\ln \left( 1+x \right) }{\sin x} \right)  }=e^{ \lim_{ x \to 0 } \left( \frac{\ln \left( 1+x \right) }{\sin x} \right)  }=e^{ 1 }
$$
עוד דרך
$$
\left( 1+x \right)^{\frac{1}{\sin x}} = \left( 1+x \right)^{\frac{1}{x}\cdot \frac{x}{\sin x}}
$$
