# הנגזרת

> [!TODO] להשוות
> עם ההגדרה ב[[נגזרת]]

תהא $f$ מוגדרת בסביבה של $a$, נאמר כי $f$ גזירה בנקודה $a$, אם קיים הגבול (הסופי):
$$
\lim_{ x \to a } \frac{f\left( x \right) -f\left( a \right) }{x-a}
$$

> [!NOTE] גבול של מי?
> זהו גבול של פונקציה "חדשה" $g\left( x \right)= \frac{f\left( x \right)-f\left( a \right)}{x-a}$ שמוגדרת לכל $x\neq 0$, זו פונקציה השיפוע של $f$ בנקודה $a$

באופן שקול, ניתן להשתמש בגבול
$$
\lim_{ h \to 0 } \frac{f\left( a+h \right) -f\left( a \right) }{h}
$$

> [!INFO] הסבר
> ע"י ההצבה: $h\left( x \right)=x-a$ ושימוש של ההרכבה $g\left( x \right)\xrightarrow{ x\to a }$

אם קיים הגבול, נאמר כי $f$ גזירה בנקודה $a$, ונסמן:
$$
f'\left( a \right) = \lim_{ x \to a } \frac{f\left( x \right) -f\left( a \right) }{x-a}
$$
## גזירה ברציפות
נאמר על $f$ שהיא <u>רציפה ברציפות</u> אם $f$ גזירה לכל נקודה בתחום הגדרה, וגם $f'$ רציפה
## כלל השרשרת
אם $f$ גזירה ב-$a$. ו-$g$ גזירה ב-$f\left( a \right)$ אזי $\left( g\circ f \right)$ גזירה בנקודה $a$.
ובנוסף:
$$
\left( g \circ f \right)' \left( a \right) = g'\left( f\left( a \right)  \right) \cdot f'\left( a \right) 
$$
# תרגיל 1
הוכיחו/הפריכו
### א
$f$ גזירה ב-$a$ $\impliedby$ $f$ רציפה ב-$a$
### ב
$f$ גזירה ב-$a$ $\impliedby$ $f$ רציפה בסביבה של $a$
## פתרון 1
### א
הוכחנו בכית
### ב
לא נכון! דוגמה נגדית
$$
\begin{gather}
D\left( x \right) = \begin{cases}
x^{2} & x \in \mathbb{Q} \\
0 & x\not\in \mathbb{Q}
\end{cases} \\
f\left( x \right) = x^{2} \cdot D\left( x \right) 
\end{gather}
$$
נראה כי $f$ גזירה ב-$0$
נראה שקיים הגבול
$$
\lim_{ x \to 0 } \frac{f\left( x \right) -f\left( 0 \right) }{x-0} = \lim_{ x \to 0 } \frac{x^{2}\cdot D\left( x \right) }{x}= \lim_{ x \to 0 } x\cdot D\left( x \right) 
$$
נגדיר 
$$
g\left( x \right) =x\cdot D\left( x \right) 
$$
באופן שקול נראה שלכל 
$$
\begin{gather}
\mathbb{Q} \ni q_{n} \neq 0 \to 0, g\left( q_{n} \right) \to L \\
\mathbb{Q} \not\ni r_{n} \neq 0 \to 0, g\left( r_{n} \right) \to L
\end{gather}
$$
$$
\begin{gather}
g\left( q_{n} \right) = q_{n} \cdot D\left( q_{n} \right) = q_{n} \to 0 \\
g\left( r_{n} \right) = r_{n} \cdot D\left( r_{n} \right) = r_{n} \cdot 0 \to 0
\end{gather}
$$
ולכן על פי משפט שהראנו בכיתה
$$
\lim_{ x \to 0 } x\cdot D\left( x \right) =0
$$
ולכן $f$ גזירה ב $x=0$ ונגזרתה $0$
הראנו ב[[תואר/סיכומים/סמסטר א/אינפי 1/גליון 4#פתרון 5|גליון]] ש $f$ רציפה ב-$x_{0}$ ושלא קיים לא גבול באף נקודה אחרת, ובפרט היא אינה רציפה בסביבה של $0$

## פתרון 2
### הפונקציה $f_{0}$
ראינו ש $\lim_{ x \to 0 }\sin \frac{1}{x}$ לא קיים, ולכן ל-$f_{9}$ לא קיים הגבול ב-$0$ ולכן בפרט היא לא רציפה ב-$0$ ולכן לא רציפה.
###  הפונקציה $f_{1}$
לכל $x\neq 0$ מתקיים $f_{1}\left( x \right)=x \sin \frac{1}{x}$ וזו רציפה כמכפלה והרכבה של אלמנטריות בתחום הגדרתן
נבדוק רציפות ב-$0$
$$
\lim_{ x \to 0 } f_{1}\left( x \right) = \lim_{ x \to 0 }  x \cdot \sin \frac{1}{x}\underset{ \text{Bounded times zero'd} }{ = } 0 = f_{1}\left( 0 \right) 
$$
ולכן $f_{1}$ רציפה גם ב-$0$ ועל כן רציפה
נבדוק אם $f_{1}$ גזירה ב$x=0$
$$
\lim_{ x \to 0 } \frac{f_{1}\left( x \right) -f_{1}\left( 0 \right) }{x-0}= \lim_{ x \to 0 } \frac{x \sin \frac{1}{x}}{x}= \lim_{ x \to 0 }  \sin \frac{1}{x}=\text{DNE}
$$
ולכן $f_{1}$ לא גזירה
### הפונקציה $f_{2}$
לכל $x\neq 0$, $f_{2}$ גזירה כהרכבה ומכפלה של גזירות (לפי כלל השרשרת)
נבדוק גזירות ב$x=0$
$$
\lim_{ x \to 0 } \frac{f_{2}\left( x \right) -f_{2}\left( 0 \right) }{x-0}=\lim_{ x \to 0 } \frac{x^{2}\sin \frac{1}{x}- 0}{x-0}= \lim_{ x \to 0 } x \sin \frac{1}{x}= 0
$$
ולכן גזירה גם ב-$0$, ולכן $f_{2}$ גזירה בכל מקום, ממשפט, $f_{2}$ גזירה $\impliedby$ $f_{2}$ רציפה
נמצא את הנגזרת של $f_{2}$
$$

f'\left( 0 \right) =0
$$
לכל $x \neq 0$
$$
\left( f_{2}\left( x \right)  \right)' = \left( x^{2}\cdot \sin \frac{1}{x} \right)'= 2x\cdot \sin \frac{1}{x} + x^{2} \left( \sin \frac{1}{x} \right)' \underset{ \text{Chain rule} }{ = } \cos \frac{1}{x} \cdot -\frac{1}{x^{2}}
$$
נבדוק אם $f_{2}'\left( x \right)$ רציפה
$$
f_{2}'\left( x \right) = \begin{cases}
2x \sin \frac{1}{x}-\cos \frac{1}{x} & x\neq 0 \\
0 & x = 0
\end{cases}
$$
נניח בשלילה $L=\lim_{ x \to 0 }f_{2}'\left( x \right)=L$
נקבל
$$
\cos \frac{1}{x}= 2x \sin \frac{1}{x}-f_{2}'\left( x \right)  \xrightarrow{ x\to 0 }0 -L = -L
$$
בסתירה לכך ש $\cos \frac{1}{x}\xrightarrow{ x\to 0 }DNE$ (אנחנו בתרגול אז לא נוכיח את זה שהגבול הזה של קוסינוס לא קיים, אבל בגליון/מבחן כן צריך)
