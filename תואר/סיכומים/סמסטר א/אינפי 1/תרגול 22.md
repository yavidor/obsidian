# הנגזרת

> [!TODO] להשוות
> עם ההגדרה ב[[נגזרת]]

תהא $f$ מוגדרת בסביבה של $a$, נאמר כי $f$ גזירה בנקודה $a$, אם קיים הגבול (הסופי):
$$
\lim_{ x \to a } \frac{f\left( x \right) -f\left( a \right) }{x-a}
$$

> [!NOTE] גבול של מי?
> זהו גבול של פונקציה "חדשה" $g\left( x \right)= \frac{f\left( x \right)-f\left( a \right)}{x-a}$ שמוגדרת לכל $x\neq 0$, זו פונקציה השיפוע של $f$ בנקודה $a$

באופן שקול, ניתן להשתמש בגבול
$$
\lim_{ h \to 0 } \frac{f\left( a+h \right) -f\left( a \right) }{h}
$$

> [!INFO] הסבר
> ע"י ההצבה: $h\left( x \right)=x-a$ ושימוש של ההרכבה $g\left( x \right)\xrightarrow{ x\to a }$

אם קיים הגבול, נאמר כי $f$ גזירה בנקודה $a$, ונסמן:
$$
f'\left( a \right) = \lim_{ x \to a } \frac{f\left( x \right) -f\left( a \right) }{x-a}
$$
## גזירה ברציפות
נאמר על $f$ שהיא <u>רציפה ברציפות</u> אם $f$ גזירה לכל נקודה בתחום הגדרה, וגם $f'$ רציפה
## כלל השרשרת
אם $f$ גזירה ב-$a$. ו-$g$ גזירה ב-$f\left( a \right)$ אזי $\left( g\circ f \right)$ גזירה בנקודה $a$.
ובנוסף:
$$
\left( g \circ f \right)' \left( a \right) = g'\left( f\left( a \right)  \right) \cdot f'\left( a \right) 
$$
## נגזרת של פונקציה הופכית
תהא $f$ הפיכה, גזירה ב-$x_{0}$, רציפה בסביבתה של $x_{0}$ ומקיימת $f'\left( x_{0} \right)\neq 0$
אזי $f^{-1}$ גזירה ב$f\left( x_{0} \right)$ ומתקיים
$$
\left( f^{-1} \right)' \left( f\left( x \right)  \right)= \frac{1}{f'\left( x_{0} \right) }
$$
זה קצת מבלבל מה קורה פה אז נסמן $y_{0}=f\left( x_{0} \right)$
נסמן $y_{0}=f\left( x_{0} \right)$ ואז
$$
\left( f^{-1} \right)'\left( y_{0} \right) = \frac{1}{f'\left( x_{0} \right) }
$$

### ב

## פתרון 1
### א
הוכחנו בכית
### ב
לא נכון! דוגמה נגדית
$$
\begin{gather}
D\left( x \right) = \begin{cases}
x^{2} & x \in \mathbb{Q} \\
0 & x\not\in \mathbb{Q}
\end{cases} \\
f\left( x \right) = x^{2} \cdot D\left( x \right) 
\end{gather}
$$
נראה כי $f$ גזירה ב-$0$
נראה שקיים הגבול
$$
\lim_{ x \to 0 } \frac{f\left( x \right) -f\left( 0 \right) }{x-0} = \lim_{ x \to 0 } \frac{x^{2}\cdot D\left( x \right) }{x}= \lim_{ x \to 0 } x\cdot D\left( x \right) 
$$
נגדיר 
$$
g\left( x \right) =x\cdot D\left( x \right) 
$$
באופן שקול נראה שלכל 
$$
\begin{gather}
\mathbb{Q} \ni q_{n} \neq 0 \to 0, g\left( q_{n} \right) \to L \\
\mathbb{Q} \not\ni r_{n} \neq 0 \to 0, g\left( r_{n} \right) \to L
\end{gather}
$$
$$
\begin{gather}
g\left( q_{n} \right) = q_{n} \cdot D\left( q_{n} \right) = q_{n} \to 0 \\
g\left( r_{n} \right) = r_{n} \cdot D\left( r_{n} \right) = r_{n} \cdot 0 \to 0
\end{gather}
$$
ולכן על פי משפט שהראנו בכיתה
$$
\lim_{ x \to 0 } x\cdot D\left( x \right) =0
$$
ולכן $f$ גזירה ב $x=0$ ונגזרתה $0$
הראנו ב[[תואר/סיכומים/סמסטר א/אינפי 1/גליון 4#פתרון 5|גליון]] ש $f$ רציפה ב-$x_{0}$ ושלא קיים לא גבול באף נקודה אחרת, ובפרט היא אינה רציפה בסביבה של $0$

# תרגיל 2
בדקו אם הפונקציות הבאות רציפות, גזירות וגזירות ברציפות

$$
\begin{gather}
f_{0}\left( x \right) = \begin{cases}
\sin \frac{1}{x} & x \neq 0 \\
0 & x =0
\end{cases} \\
f_{1}\left( x \right) = \begin{cases}
x\cdot \sin \frac{1}{x} & x \neq 0 \\
0 & x =0
\end{cases} \\
f_{2}\left( x \right) = \begin{cases}
x^{2}\cdot \sin \frac{1}{x} & x\neq 0 \\
0 & x = 0
\end{cases}
\end{gather}
$$
## פתרון 2
### הפונקציה $f_{0}$
ראינו ש $\lim_{ x \to 0 }\sin \frac{1}{x}$ לא קיים, ולכן ל-$f_{9}$ לא קיים הגבול ב-$0$ ולכן בפרט היא לא רציפה ב-$0$ ולכן לא רציפה.
###  הפונקציה $f_{1}$
לכל $x\neq 0$ מתקיים $f_{1}\left( x \right)=x \sin \frac{1}{x}$ וזו רציפה כמכפלה והרכבה של אלמנטריות בתחום הגדרתן
נבדוק רציפות ב-$0$
$$
\lim_{ x \to 0 } f_{1}\left( x \right) = \lim_{ x \to 0 }  x \cdot \sin \frac{1}{x}\underset{ \text{Bounded times zero'd} }{ = } 0 = f_{1}\left( 0 \right) 
$$
ולכן $f_{1}$ רציפה גם ב-$0$ ועל כן רציפה
נבדוק אם $f_{1}$ גזירה ב$x=0$
$$
\lim_{ x \to 0 } \frac{f_{1}\left( x \right) -f_{1}\left( 0 \right) }{x-0}= \lim_{ x \to 0 } \frac{x \sin \frac{1}{x}}{x}= \lim_{ x \to 0 }  \sin \frac{1}{x}=\text{DNE}
$$
ולכן $f_{1}$ לא גזירה
### הפונקציה $f_{2}$
לכל $x\neq 0$, $f_{2}$ גזירה כהרכבה ומכפלה של גזירות (לפי כלל השרשרת)
נבדוק גזירות ב$x=0$
$$
\lim_{ x \to 0 } \frac{f_{2}\left( x \right) -f_{2}\left( 0 \right) }{x-0}=\lim_{ x \to 0 } \frac{x^{2}\sin \frac{1}{x}- 0}{x-0}= \lim_{ x \to 0 } x \sin \frac{1}{x}= 0
$$
ולכן גזירה גם ב-$0$, ולכן $f_{2}$ גזירה בכל מקום, ממשפט, $f_{2}$ גזירה $\impliedby$ $f_{2}$ רציפה
נמצא את הנגזרת של $f_{2}$
$$

f'\left( 0 \right) =0
$$
לכל $x \neq 0$
$$
\left( f_{2}\left( x \right)  \right)' = \left( x^{2}\cdot \sin \frac{1}{x} \right)'= 2x\cdot \sin \frac{1}{x} + x^{2} \left( \sin \frac{1}{x} \right)' \underset{ \text{Chain rule} }{ = } \cos \frac{1}{x} \cdot -\frac{1}{x^{2}}
$$
נבדוק אם $f_{2}'\left( x \right)$ רציפה
$$
f_{2}'\left( x \right) = \begin{cases}
2x \sin \frac{1}{x}-\cos \frac{1}{x} & x\neq 0 \\
0 & x = 0
\end{cases}
$$
נניח בשלילה $L=\lim_{ x \to 0 }f_{2}'\left( x \right)=L$
נקבל
$$
\cos \frac{1}{x}= 2x \sin \frac{1}{x}-f_{2}'\left( x \right)  \xrightarrow{ x\to 0 }0 -L = -L
$$
בסתירה לכך ש $\cos \frac{1}{x}\xrightarrow{ x\to 0 }DNE$ (אנחנו בתרגול אז לא נוכיח את זה שהגבול הזה של קוסינוס לא קיים, אבל בגליון/מבחן כן צריך)
# תרגיל 3 ([[סדרה|סדרות]])
יהי $a>0$, חשבו את הגבול
$$
\lim_{ n \to \infty } n \cdot \left( \sqrt[n]{a}-1 \right) 
$$
## רעיון פתרון 3
$$
n\left( \sqrt[n]{a}-1 \right) = \frac{\sqrt[n]{a}-1}{\frac{1}{n}}= \frac{a^{1/n}-a^{0}}{\frac{1}{n}-0}
$$
הולי שיט זה נגזרת
## פתרון 3
נתבונן בפונקציה $f\left( x \right)=a^{x}$
$$
\begin{gather}
\left( a^{x} \right)' = \left( e^{ \ln \left( a^{x} \right)  } \right)' \\
=\left( e^{ x\ln a } \right)' \underset{ \text{Chain rule} }{ = } e^{ x\ln \left( a \right)  }\cdot \ln \left( a \right) =a^{x}\cdot \ln \left( a \right) =a^{x}\cdot \ln \left( x \right) 
\end{gather}
$$
בפרט, $f$ גזירה ב$x=0$ ומתקיים
$$
f'\left( 0 \right) =\ln \left( a \right) 
$$
ולפי הגדרת הנגזרת
$$
\lim_{ x \to 0 } \frac{a^{x}-a^{0}}{x-0} = \ln \left( a \right)
$$
לפי היינה, לכל $0 \neq x_{n} \to 0$ מתקיים
$$
\frac{a^{x_{n}}-a^{0}}{x_{n}-0}\to \ln \left( a \right) 
$$
נבחר
$$
0 \neq \frac{1}{n}= x_{n} \to 0
$$
לכן הגבול הוא $\ln \left( a \right)$

$$
המקיימת
$$
\forall n\in \mathbb{N}f\left( \sin \left( \frac{1}{n} \right)  \right) =\cos \left( \frac{1}{n} \right) 
$$

## פתרון 4
### א
$f$ גזירה ב-$0$ $\impliedby$ $f$ רציפה ב-$0$ $\impliedby$ $\lim_{ x \to 0 }f\left( x \right)=f\left( 0 \right)$
לפי היינה, לכל $x_{n} \to 0$ מתקיים $f\left( x_{n} \right)\to f\left( 0 \right)$ 
בפרט $x_{n}= \sin \left( \frac{1}{n} \right)\xrightarrow{ n\to \infty }0$ כי מהיינה $\frac{1}{n}\to 0, \sin \left( x \right)\xrightarrow{ x\to 0 }\sin \left( 0 \right)=0$
ולכן:
$$
f\left( 0 \right) =\lim_{ n \to \infty } f\left( \sin \left( \frac{1}{n} \right) \right) =\lim_{ n \to \infty } \cos \left( \frac{1}{n} \right) 
$$
לפי היינה
$$
\begin{gather}
\frac{1}{n} \xrightarrow{ n\to \infty } 0 \\
\cos \left( x \right) \xrightarrow{ x\to 0 }1
\end{gather}
$$
$$
\lim_{ n \to \infty }\cos \left( \frac{1}{n} \right) =1 
$$
### ב
$$
f'\left( 0 \right) = \lim_{ x \to 0 } \frac{f\left( x \right) -f\left( 0 \right) }{x-0}= \lim_{ x \to 0 } \frac{f\left( x \right) -1}{x}
$$
לפי קריטריון היינה כש $x_{n}=\sin \left( \frac{1}{n} \right)$ זה שווה ל
$$
\lim_{ n \to \infty } \frac{f\left( \sin \left( \frac{1}{n} \right)  \right)-1 }{\sin \left( \frac{1}{n} \right)}=\lim_{ n \to \infty }  \frac{\cos \left( \frac{1}{n} \right) -1}{\sin \left( \frac{1}{n} \right) }
$$
עומר מלך ולכן ננסה להימנע מ[[משפטים בטריגונומטריה]], נכפיל בצמוד
$$
\begin{gather}
= \lim_{ n \to \infty } \frac{\cos ^{2}\left( \frac{1}{n} \right) -1}{\left( \sin \left( \frac{1}{n} \right) \left( \cos \left( \frac{1}{n} \right) +1 \right)  \right) } \\
=\lim_{ n \to \infty }  \frac{-\sin ^{\cancel{2}}\left( \frac{1}{n} \right) }{\cancel{\sin\left( \frac{1}{n}  \right)}  \underset{ \to 2 }{ \left( \cos \frac{1}{n}+1 \right) } } = \frac{0}{2}=0
\end{gather}
$$
# תרגיל 5
הוכיחו כי הפונקציה:
$$
\begin{gather}
f:\left[ 0,\infty \right) \to \mathbb{R} \\
f\left( x \right) =x^{\left( x^{x} \right) }
\end{gather}
$$
גזירה ב-$\left( 0,\infty \right)$ ומצאו את נגזרתה.
## פתרון 5
נתבונן ב$\left( x^{x} \right)$:
$$
x^{x}= e^{ \ln \left( x^{x} \right)  }=e^{ x\ln \left( x \right)  }
$$
ולכן $x^{x}$ היא מכפלה והרכבה של אלמנטריות, ולכן היא מכלל השרשרת היא גזירה (כאשר $x\neq 0$)
ולכן מכלל השרשרת
$$
\left( x^{x} \right)' = \left( e^{ x\ln \left( x \right)  } \right)' = e^{ x\ln x }\cdot \left( x\ln x \right)'= x^{x}\cdot \left( \ln x + \frac{1}{x}x  \right) =x^{x}\cdot \left( \ln (x)+1 \right) 
$$
נתבונן ב$x^{\left( x^{x} \right)}$:
$$
x^{\left( x^{x} \right) }=e^{ \left( x^{x} \right) \ln \left( x \right)  }
$$
ולכן גזירה כהרבה ומכפלה של גזירות
$$
\begin{gather}

(x^{\left( x^{x} \right)})' = \left( e^{ \left( x^{x} \right) \ln x } \right)'  \\
\underset{ \text{Chain} }{ = } 
e^{ \left( x^{x} \right) \ln x}\cdot \left( \left( x^{x} \right) \cdot \ln \left( x \right)  \right)'=x^{\left( x^{x} \right) }\left( x^{x}\left( \ln \left( x \right) +1 \right) \cdot \ln \left( x \right) +x^{x}\cdot \frac{1}{x} \right) 
\end{gather}
$$
