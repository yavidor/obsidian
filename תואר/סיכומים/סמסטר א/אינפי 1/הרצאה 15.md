# חוב משבוע שעבר
לא הבנתי מה קורה פה, לא הבנתי איך זה קשור לשבוע שעבר
מה נאמר לגבי זה שבוע שעבר?
$$
\lim_{ x \to 0 } \frac{\sin x}{x}=1
$$
נוכיח באמצעות קצת כיף של טריגו
## הוכחה
נראה ש $\lim_{ x \to 0^{+} } \frac{\sin x}{x}=1$
מזה נובע ש
$$
\lim_{ x \to 0^{-} } \frac{\sin x}{x} = \lim_{ x \to 0^{+} } \frac{\sin \left( -x \right) }{x}=\lim_{ x \to 0^{+} }  \frac{\sin x}{x}=1
$$
לא ברור לי למה
כעת נניח ש $0<x < \frac{\pi}{2}$
ואז הוא עשה קסמים עם משולשים ומעגל היחידה ומשהו משהו הופה יש הוכחה
קיבלנו משהו
$$
\sin x<x< \tan x \implies 1 < \frac{\sin x}{x} < \cos x
$$
אם $x\to 0$ אז $1\to 1$ ו$\cos x \to 1$ לכן מסנדוויץ' $\frac{\sin x}{x}\to 1$

## דוגמת שימוש
$\lim_{ n \to \infty }n \sin \left( \frac{1}{n} \right)=\lim_{ n \to \infty } \frac{\sin \left( \frac{1}{n} \right)}{\frac{1}{n}}=1$

$\lim_{ x \to x_{0} }f\left( x \right)=\infty$ אם לכל $M$ קיים $\delta>0$ כך שלכל $x$ אם $0<\left| x-x_{0} \right|<\delta$ אזי $f\left( x \right)>M$
באופן דומה מגדירים [[גבול חד צדדי|גבולות חד-צדדיים]], גבולות באינסוף וכדומה.

אם $\lim_{ x \to x_{0} }f\left( x \right)=\infty$ אזי $\lim_{ x \to x_{0} }g\left( x \right)=\infty$
