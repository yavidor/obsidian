# משפט
תהא $f$ רציפה בסביבות $x_{0}$ וגזירה בסביבה מנוקבת של $x_{0}$
אזי אם $\lim_{ x \to x_{0} }f'\left( x \right)=L\in \mathbb{R}$
אזי $f$ גזירה ב-$x_{0}$ ומתקיים $f'\left( x_{0} \right)=L$
## הוכחה
נוכיח כי $f_{+}'\left( x_{0} \right)=f_{-}'\left( x_{0} \right)=L$ ומכי ינבע כי $f$ גזירה ב-$x_{0}$ ו$f'\left( x_{0} \right)=L$

יהא $h>0$
$$
\frac{f\left( x_{0}+h \right) -f\left( x_{0} \right) }{h}=f'\left( \underset{ \xrightarrow{h\to 0 }L}{ x_{0}+\alpha h } \right) 
$$

> [!HELP] אלפא?
> לא הבנתי מאיפה האלפא
> כתוב על הלוח: קיים $0<\alpha<1$
> בנוסף איכשהו זה משתמש בלגראנג' אבל לא לגמרי הבנתי איך

ולכן מתקיים
$$
\lim_{ h \to 0^{+} }  \frac{f\left( x_{0}+h \right) -f\left( x_{0} \right) }{h}=L
$$
באופן דומה מראים כי
$$
\lim_{ h \to 0^{-} } \frac{f\left( x_{0}+h \right) -f\left( x_{0} \right) }{h}=L
$$
ולכן $f'\left( x_{0}\right)=L$

# דוגמה
דוגמה לפונקציה $f:\left[ -1,1 \right]\to \mathbb{R}$ אשר [[נגזרת|גזירה]] בכל $\left[ -1,1 \right]$ אבל איננה חסומה
$$
f\left( x \right) = \left| x \right|^{3/2} \sin \left( \frac{1}{x} \right) , f\left( 0 \right) =0
$$
$$
\begin{gather}
\lim_{ x \to 0^{+} }  \frac{f\left( x \right) -f\left( 0 \right) }{x}= \lim_{ x \to 0^{+} } \frac{x^{3/2} \cdot \sin \left( \frac{1}{x} \right) - 0}{x}= \lim_{ x \to 0^{+} } \sqrt{x}\cdot \sin \left( \frac{1}{x} \right) =0 \\
\lim_{ x \to 0^{-} } \frac{f\left( x \right) -f\left( 0 \right) }{x}= \lim_{ x \to 0^{-} } \frac{-x^{2/3} \sin \left( \frac{1}{x} \right) }{x} = \lim_{ x \to 0^{-} } \underset{ \to 0 }{ \sqrt{x} }\cdot \underset{ \text{bounded} }{ \sin \left( \frac{1}{x} \right) } =0
\end{gather}
$$
עכשיו כשטיפלנו בנקודה הבעייתית, נחלק למקרים
$$
f'\left( x \right) =\begin{cases}
\frac{3}{2}\sqrt{x} \sin \left( \frac{1}{x} \right) -\frac{1}{\sqrt{x}}\cdot\cos \left( \frac{1}{x} \right)  & x>0 \\
0 & 0 \\
\dots & x < 0
\end{cases}
$$
אם כך הנגזרת לא חסומה, ויותר מזה היא מתפוצצת, אז גם הפונקציה עצמה לא חסומה כי היא לא מפסיקה לעלות בשיפוע הולך ועולה
