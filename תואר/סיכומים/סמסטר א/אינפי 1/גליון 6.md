# שאלה 1
עבור אילו ערכי $p$ ו-$q>0$ הפונקציה
$$
f\left( x \right) =\begin{cases}
\left| x \right| ^{p}\cos \left( \frac{\pi}{\left| x \right| ^{q}} \right)  & x\neq 0 \\
0 & x=0
\end{cases}
$$
רציפה באפס? גזירה באפס? גזירה ברציפות באפס?
# פתרון 1
נבדוק רציפות
נתבונן בגבול של הפונקציה כש-$x$ שואף ל-$0$
$$
\lim_{ x \to 0 } \left| x \right| ^{p}\cos \left( \frac{\pi}{\left| x \right| ^{q}} \right) 
$$
על מנת שהפונקציה תהיה רציפה ב-$0$ נדרוש כי הגבול יהיה שווה ל-$0$
נפרק למקרים על פי ערכי $p$
עבור $p>0$

$$
\lim_{ x \to 0 } \left| x \right| ^{p} = 0
$$
בנוסף, נטען כי $\lim_{ x \to 0 } \cos \left( \frac{\pi}{\left| x \right|^{q}} \right)$ לא קיים.
בדומה למה שראינו בכיתה עם $\sin \left( \frac{1}{x} \right)$, נשתמש בקריטריון היינה
נגדיר שתי סדרות
$$
\begin{gather}
x_{n} = \sqrt[q]{\frac{1}{2n}}\xrightarrow{ n\to \infty } \sqrt[q]{0}= 0 \\
y_{n}=\sqrt[q]{\frac{1}{2n+1}} \xrightarrow{n\to \infty  } \sqrt[q]{0} = 0
\end{gather}
$$
נתבונן ב-$\cos\left( \frac{\pi}{\left| x_{n} \right| ^{q}} \right)$ ו-$\cos\left( \frac{\pi}{\left| y_{n} \right| ^{q}} \right)$
$$
\begin{gather}
\lim_{ n \to \infty } \cos \left( \frac{\pi}{\left| x_{n} \right| ^{q}} \right) =\lim_{ n \to \infty } \cos\left( \frac{\pi}{\left| \sqrt[q]{ \frac{1}{2n} } \right| ^{q}} \right) \\ 
\underset{ \sqrt{x}>0 }{ = }\lim_{ n \to \infty } \cos\left( \frac{\pi}{ \sqrt[q]{ \frac{1}{2n} }  ^{q}} \right)  \\
\underset{ \sqrt[q]{x}^{q}=x }{ = }\lim_{ n \to \infty } \cos\left( \frac{\pi}{  \frac{1}{2n} } \right) \\
=\lim_{ n \to \infty } \cos \left( 2n\pi \right)  =1
\end{gather}
$$
ובצורה דומה
$$
\begin{gather}
\lim_{ n \to \infty } \cos \left( \frac{\pi}{\left| y_{n} \right| ^{q}} \right) =\lim_{ n \to \infty } \cos\left( \frac{\pi}{\left| \sqrt[q]{ \frac{1}{2n+1} } \right| ^{q}} \right) \\ 
=\lim_{ n \to \infty } \cos\left( \frac{\pi}{ \sqrt[q]{ \frac{1}{2n+1} }  ^{q}} \right)  \\
=\lim_{ n \to \infty } \cos\left( \frac{\pi}{  \frac{1}{2n+1} } \right) \\
=\lim_{ n \to \infty } \cos \left( (2n+1)\pi \right)  =-1
\end{gather}
$$
$\lim_{ n \to \infty }\cos\left( \frac{\pi}{\left| x_{n} \right| ^{q}} \right)\neq \lim_{ n \to \infty }\cos\left( \frac{\pi}{\left| y_{n} \right| ^{q}} \right)$ אבל $\lim_{ n \to \infty }x_{n}=\lim_{ n \to \infty }y_{n}=0$, על פי היינה זה אומר שלא קיים $\lim_{ x \to 0 }\cos\left( \frac{\pi}{\left| x\right| ^{q}} \right)$
וידוע כי $\cos$ חסומה בין $1$ ל-$-1$, ולכן "חסומה כפול אפסה"
$$
\lim_{ x \to 0 } \underset{ \to 0 }{ \left| x \right| } ^{p}~~\underset{ \text{Bounded} }{ \cos \left( \frac{\pi}{\left| x \right| ^{q}} \right) } = 0
$$
כלומר עבור $p>0$, לכל $q>0$ $f$ רציפה ב-$0$
עבור $p<0$
נשתמש באותן סדרות $x_{n}$, $y_{n}$
$$
\begin{gather}
\lim_{ n \to \infty } f\left( x_{n} \right)  \\
=\lim_{ n \to \infty } \left| \sqrt[q]{\frac{1}{2n}} \right|^{p}\cdot \cos \left( \frac{\pi}{\left| \sqrt[q]{\frac{1}{2n}} \right| ^{q}} \right)  \\
= \lim_{ n \to \infty }  \frac{\overbrace{ \cos \left( 2\pi n \right) }^{ \to 1 }}{\underbrace{ \left(\sqrt[q]{\frac{1}{2n}} \right)^{-p} }_{ \to 0 }} \\
= \infty
\end{gather}
$$
$$
\begin{gather}
\lim_{ n \to \infty } f\left( y_{n} \right)  \\
=\lim_{ n \to \infty } \left| \sqrt[q]{\frac{1}{2n+1}} \right|^{p}\cdot \cos \left( \frac{\pi}{\left| \sqrt[q]{\frac{1}{2n+1}} \right| ^{q}} \right)  \\
= \lim_{ n \to \infty }  \frac{\overbrace{ \cos \left( \left( 2n+1 \right) \pi \right) }^{ \to -1 }}{\underbrace{ \left(\sqrt[q]{\frac{1}{2n+1}} \right)^{-p} }_{ \to 0 }} \\
= -\infty
\end{gather}
$$
שני הגבולות שונים ולכן כש$p<0$, לכל $q>0$, $f$ לא רציפה

עבור $p=0$

$$
\lim_{ x \to 0 } \left| x \right| ^{0}=\left| x \right| ^{0}=1
$$
ולכן
$$
\lim_{ x \to 0 } \left| x \right| ^{0} \cos \left( \frac{\pi}{\left| x \right| ^{q}} \right) = \lim_{ x \to 0 } \cos \left( \frac{\pi}{\left| x \right| ^{q}} \right) =\text{D.N.E}
$$

ולכן כאשר $p=0$, לכל $q>0$, $f$ לא רציפה ב-$0$
לסיכום, קיבלנו שכל $p>0$, לכל $q>0$. $f$ רציפה

נעבור לגזירות
נתעניין רק כש$p>0$ כי רק שם הפונקציה רציפה ב-$0$ ופונקציה לא רציפה היא בהכרח לא גזירה.
נבחן את הגבול
$$
\lim_{ x \to 0 } \frac{\left| x \right| ^{p}\cdot \cos \left( \frac{\pi}{\left| x \right| ^{q}} \right) }{x}=\lim_{ x \to 0 } \left| x \right| ^{p-1}\cdot\cos \left( \frac{\pi}{\left| x \right| ^{q}} \right) 
$$
נגדיר $k:=p$ ונראה כי
$$
\lim_{ x \to 0 } \left| x \right| ^{k} \cdot \cos \left( \frac{\pi}{\left| x \right| ^{q}} \right)
$$
כפי שראינו, הגבול הנ"ל קיים רק כש-$k>0$, כלומר כש$p-1>0$, מכאן שהגבול הנ"ל קיים רק כש$p>1$
נעבור לגזירות ברציפות
על מנת לבדוק את זה, נמצא את הנגזרת של $f$, נניח $p>1$ כי רק אז הנגזרת קיימת
$$
f'\left( x \right) =\left( \left| x \right|^{p} \cdot  \cos \left( \frac{\pi}{\left| x \right| ^{q}} \right) \right)' = \left( \left| x \right| ^{p} \right)'\cdot \cos \left( \frac{\pi}{\left| x \right| ^{q}} \right) + \left( \cos \left( \frac{\pi}{\left| x \right| ^{q}} \right)  \right)'\cdot \left( \left| x \right| ^{p} \right) 
$$
