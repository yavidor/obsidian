# שאלה 3
הוכיחו לפי הגדרה
א.
$$
\lim_{ x \to \frac{1}{9} } \frac{1}{\sqrt{x}}   =3
$$
ב.
$$
\lim_{ x \to \infty }  \frac{-9x^{2}+9x}{2x^{2}+8} = -\frac{9}{2}
$$
# פתרון 3
א.
יהי $\epsilon>0$, נחפש $\delta>0$ כך ש
$$
0<\left| x-\frac{1}{9} \right|  < \delta \implies \left| \frac{1}{\sqrt{x}}- 3 \right|<\epsilon 
$$
נתבונן בצד הימני של הביטוי
נרצה להגדיל את הביטוי

$$
\begin{gather}
\left| \frac{1}{\sqrt{x}}-3 \right| = \left| \frac{1-3\sqrt{x}}{\sqrt{x}} \right|  = \left| \frac{1-3 \sqrt{x}}{\sqrt{x}} \cdot \frac{1+3\sqrt{x}}{1+ 3 \sqrt{x}} \right|
= \left| \frac{1-9x}{\sqrt{x }+3x} \right|
\end{gather} 
$$
נעבור לצד השמאלי של הביטוי המקורי
$$
\begin{gather}
\left| x-\frac{1}{9} \right| <\delta \implies \left| \frac{9x-1}{9} \right| <\delta \\
\implies \frac{\left| 9x-1 \right| }{9} < \delta \implies \frac{\left| 1-9x \right| }{9} < \delta \implies \left| 1-9x \right| < 9\delta 
\end{gather}
$$
ולכן
$$
 \left| \frac{1-9x}{\sqrt{x }+3x} \right|<\left| \frac{9\delta}{\sqrt{x}+3x} \right| 
$$
נשים לב שיש לנו $\sqrt{x}$, זה אומר שתחום ההגדרה של הפונקציה הוא $x>0$, לכן $\sqrt{x}+3x$ חיובי, ואפשר להוריד ממנו את הערך המוחלט, בנוסף אנו מחפשים $\delta>0$ ולכן גם מהמונה אפשר להוריד את הערך המוחלט
$$
\left( * \right): \frac{9\delta}{\sqrt{x}+3x} < \frac{9\delta}{3x}  = \frac{3\delta}{x}
$$
נניח ש $\delta \leq  \frac{1}{10}$, נרצה לחסום את $x$ (מלמטה)
$$
 \left| x- \frac{1}{9}\right|< \frac{1}{10}  \implies \frac{-1}{10} < x -\frac{1}{9} < \frac{1}{10} \implies \frac{-1}{10}+ \frac{1}{9} < x \implies \frac{1}{90} <x
$$
ולכן
$$
\frac{3\delta}{x} < \frac{3\delta}{\frac{1}{90}} = 270\delta \leq \epsilon\implies \delta \leq \frac{\epsilon}{270}
$$
אם כך, נבחר $\delta=\min\left\{ \frac{1}{10}, \frac{\epsilon}{270} \right\}$
ואכן, לכל $\epsilon>0$, כש$\delta=\min\left\{ \frac{1}{10}, \frac{\epsilon}{270} \right\}$
$$
\begin{gather}
\left| x- \frac{1}{9} \right| \underset{ \delta \leq \frac{1}{10} }{ < }  \frac{1}{10} \implies x < \frac{1}{90} \implies \left| \frac{1}{\sqrt{x}}- 3 \right|\underset{ (*)\text{ חישוב}  }{ <  }\frac{1}{x} \cdot 3\delta  \\
< 90 \cdot 3\delta = 270\delta \underset{ \delta \leq \frac{\epsilon}{270} }{ < } \frac{\epsilon}{270}\cdot 270 = \epsilon
\end{gather}
$$
$\blacksquare$
ב.
יהי $\epsilon>0$, נרצה למצוא $M> 0$ כך שלכל $x> M$ מתקיים
$$
\left|  \frac{-9x^{2}+9x}{2x^{2}+8} + \frac{9}{2} \right|< \epsilon 
$$
נרצה להגדיל את הצד השמאלי של הביטוי
$$
\begin{gather}
\left| \frac{2\left( -9x^{2}+9x \right)+9\left( 2x^{2}+8 \right)  }{4x^{2}+16} \right| =\left| \frac{ -18x^{2}+18x +18x^{2}+72   }{4x^{2}+16} \right|  \\
= \left| \frac{18x+72}{4x^{2}+16} \right| =\left| \frac{18(x+4)}{4(x^{2}+4)} \right| =\left| \frac{9(x+4)}{2(x^{2}+4)} \right|
\end{gather}
$$
מכיוון ש$x> M>0$, $x$ חיובי, ולכן גם המכנה וגם המונה חיוביים, ואפשר להיפטר מהערך המוחלט. בנוסף, נניח ש$x>4$
$$
\begin{gather}
\frac{9\left( x+4 \right) }{2\left( x^{2}+4 \right) } < \frac{9 \cdot 2x }{2\left( x^{2}+4 \right) } = \frac{9x}{x^{2}+4} < \frac{9x}{x^{2}} = \frac{9}{x} \underset{ x \geq M }{ \leq } \frac{9}{M} \leq \epsilon \implies M \geq \frac{9}{\epsilon}
\end{gather}
$$
לכן נבחר $M=\max\left\{ 4, \frac{9}{\epsilon} \right\}$
ואכן, לכל $\epsilon>0$, כש$M=\max\left\{ 4, \frac{9}{\epsilon} \right\}$, לכל $x> M$
$$
\left|  \frac{-9x^{2}+9x}{2x^{2}+8} + \frac{9}{2} \right|=\frac{9\left( x+4 \right) }{2\left( x^{2}+4 \right) } \underset{ x > 4 }{ < } \frac{9}{x} \underset{ x > \frac{9}{\epsilon} }{ < } \frac{9}{\frac{9}{\epsilon}} = \epsilon
$$
$\blacksquare$
# שאלה 4
תהא $f$ פונקציה חיובית המוגדרת בסביבה מנוקבת של $x=0$. נתון ש$\lim_{ x \to 0 }\left( f\left( x \right)+\frac{1}{f\left( x \right)} \right)=2$. הוכיחו כי
א.
קיימת סביבה של $0$ שבה $f\left( x \right)$ חסומה
ב.
$$
\lim_{ x \to 0 }f\left( x \right)=1
$$
# פתרון 4
א.
נתון כי $f$ חיובית, לכן חסומה ממלרע על ידי $0$, נראה כי קיימת סביבה של $0$ שבה ל-$f\left( x \right)$ קיים חסם ממלעיל.
מהנתון, ידוע כי לכל $\epsilon>0$ קיים $\delta_{\epsilon}>0$ כך שלכל $x \in \left( -\delta_{\epsilon},\delta_{\epsilon} \right)\setminus \left\{ 0 \right\}$ מתקיים
$$
\left|\left(  f\left( x \right) + \frac{1}{f\left( x \right) } \right)-2 \right| <\epsilon
$$
$$
\begin{gather}
\left| \left( f\left( x \right) + \frac{1}{f\left( x \right) } \right)-2  \right|<\epsilon \implies -\epsilon < \left( f\left( x \right) + \frac{1}{f\left( x \right) } \right) -2 < \epsilon \\
\implies   f\left( x \right) + \frac{1}{f\left( x \right) }  < \epsilon+2 \\
\implies f\left( x \right)  \underset{ f\left( x \right) > 0 }{ < }f\left( x \right) + \frac{1}{f\left( x \right) }  < \epsilon+2 \implies f\left( x \right)  < \epsilon+2
\end{gather}
$$
מכיוון שזה נכון עבור כל $\epsilon$, נבחר $\epsilon=1$
ואז עבור סביבת $\delta_{1}$ נקובה של $0$ מתקיים
$$
0 < f\left( x \right)  < \underset{ 1+2 }{ 3 }
$$
ב.
יהי $\epsilon'>0$, נחפש $\delta'>0$ כך ש
$$
0<\left| x \right| <\delta' \implies \left|  f\left( x \right) -1\right|< \epsilon'
$$
מהסעיף הקודם, אנחנו יודעים שלכל $\epsilon$, עבור $\delta_{\epsilon}$, כאשר $0<\left| x \right|<\delta_{\epsilon }$ מתקיים
$$
f\left( x \right) + \frac{1}{f\left( x \right) }< \epsilon+2
$$
$$
\begin{gather}
f\left( x \right) + \frac{1}{f\left( x \right) } -2< \epsilon \implies \left( f\left( x \right) -1 \right) ^{2} < \epsilon \cdot f\left( x \right) 
\end{gather}
$$
נניח ש $\delta'\leq\delta_{\epsilon}$, ואז $3>f\left( x \right)$, ולכן
$$
\left( f\left( x \right) -1 \right) ^{2}< \epsilon \cdot 3\underset{ \sqrt{} }{ \implies } \left| f\left( x \right) -1 \right|  < \sqrt{3\epsilon}
$$
נרצה ש $\sqrt{3\epsilon}$ יהיה קטן מ$\epsilon'$, ומכיוון שידוע שלנו שאי השוויון הזה מתקיים לכל $\epsilon$, נוכל לבחור אותו להיות מה שנרצה, בפרט $\epsilon=\frac{\epsilon'^{2}}{3}$
ואז נוכל לבחור את $\delta'=\delta_{\frac{\epsilon'}{3}}$ המתאימה ואכן
$$
0<\left| x \right| <\delta' \implies \left| f\left( x \right) -1 \right| < \sqrt{\frac{\epsilon'}{3} \cdot 3}= \epsilon' 
$$
$\blacksquare$
# שאלה 5
ראיתם בכיתה את פונקציית דיריכלה $D\left( x \right)$, נגדיר
$$
f\left( x \right) = x^{2} \cdot D\left( x \right) = \begin{cases}
x^{2}, & x \in \mathbb{Q} \\
0, & x \in \mathbb{R}\setminus \mathbb{Q}
\end{cases}
$$
מצאו באילו נקודות $a \in \mathbb{R}$ הגבול $\lim_{ x \to a }f\left( x \right)$ קיים? הוכיחו תשובתכם בעזרת הגדרת הגבול בלבד.
## פתרון 5
נראה כי עבור $a=0$ קיים גבול $L$ וש-$L=0$
יהי $\epsilon>0$, נחפש $\delta>0$ כך ש
$$
0< \left| x  \right| <\delta \implies \left| f\left( x \right) \right| < \epsilon
$$
מכיוון שלכל $x$, $f\left( x \right)=x^{2}\cdot x^{2}$ או $0$, $f\left( x \right)\geq 0$ לכל $x$ ולכן אפשר להוריד את הערך המוחלט.
נפרק למקרים
אם $x$ אי רציונלי
$$
f\left( x \right) =0<\epsilon
$$
ואז $f\left( x \right) <\epsilon$ נכון תמיד
אם $x$ רציונלי
$$
f\left( x \right) = x^{2} \cdot x^{2} = x^{4}
$$
נניח ש$\delta<1$, בערכים האלה $0<\left| x \right|<\delta<1$ ולכן $\left| x \right|>x^{4}$
$$
0 <  x^{4}  <\left| x \right| < \delta  \implies (x^{4} <\delta\implies x^{4} < \epsilon)
$$
אם כך, נצטרך ש$\delta\leq\epsilon$, ולכן נבחר $\delta=\min\left\{ 1,\epsilon \right\}$.
ואכן
$$
\begin{cases}
\epsilon < 1 & \left| x \right| < \epsilon< 1 \implies x^{4} <\left| x \right|<\epsilon <1 \implies  x^{4}  < \epsilon \\
\epsilon \geq 1 & \left| x\right| <1 \implies x^{4} < \epsilon
\end{cases}
$$

כעת נראה שאין $a\neq 0$, שעבורו קיים גבול $L$
יהי $a \neq 0$, נניח בשלילה שקיים $L$ כך שלכל $\epsilon>0$, קיים $\delta>0$ כך ש
$$
0<\left| x-a \right| < \delta \implies \left| f\left( x \right) -L \right| < \epsilon
$$
נחלק למקרים לפי $x$
אם $x$ אי רציונלי
$$
0<\left| x-a \right| < \delta \implies \left| 0 -L \right| < \epsilon \implies \left| L \right| <\epsilon
$$
כלומר לכל $\epsilon>0$, $\left| L \right|<\epsilon$, וזה אפשרי אם ורק אם $L=0$
לכן מעתה נניח כי $L=0$
אם $x$ רציונלי
$$
0<\left| x-a \right| <\delta \implies \left|  x^{4}-L \right|<\epsilon
$$
$$
\left| x^{4}-L \right| <\epsilon \underset{ L=0,x^{4}>0 }{ \implies } x^{4}<\epsilon
$$
