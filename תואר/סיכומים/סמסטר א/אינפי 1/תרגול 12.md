תהי $\left( a_{n} \right)$ סדרה
נסמן ב-$\mathcal{L}$ את קבוצת הגבולות החלקיים
$$
\begin{gather}
\overline{\lim_{ n \to \infty } a_{n}}=\lim_{ n \to \infty } \text{sup}\left( a_{n} \right) =\text{sup}\left( \mathcal{L} \right)  \\
\underline{\lim_{ n \to \infty } }a_{n}=\lim_{ n \to \infty } \text{inf}\left( a_{n} \right) =\text{inf}\left( \mathcal{L} \right) 
\end{gather}
$$
## משפט
$\underline{\lim},\overline{\lim}\in \mathcal{L}$


# תרגיל
תהא $\left( a_{n} \right)$ סדרה חסומה
הוכיחו כי לכל $\epsilon>0$ קיים $N \in \mathbb{N}$, לכל $\mathbb{N}\ni n>N$ מתקיים
$$
\underline{\lim_{ n \to \infty } a_{n}}-\epsilon<a_{n}<\overline{\lim_{ n \to \infty } a_{n}}+\epsilon
$$
## פתרון
### למה לתרגול בית
$\left( a_{n} \right)$ חסומה $\impliedby$ $\overline{\lim_{ n \to \infty }a_{n}}$ קיים
נגדיר $\mathcal{L}$ כקבוצת הגבולות החלקיים
מכיוון ש$\left( a_{n} \right)$ חסומה, על פי משפט BW קיימת לה [[תת סדרה|תת-סדרה]] מתכנסת, כלומר $\mathcal{L}\neq \emptyset$
נניח בשלילה ש-$\mathcal{L}$ לא חסומה

נניח בשלילה שהטענה לא מתקיימת, כלומר:

נבנה באינדוקציה תת סדרה $\left( a_{n_{k}} \right)$ המקיימת $a_{n_{k}}\geq\overline{\lim_{ n \to \infty }}a_{n}+\epsilon$
<u>בסיס</u>: עבור $N=1$, קיים $n_{1}>N_{1}$ המקיים $a_{n}\geq\overline{\lim_{ n \to \infty }}a_{n}+\epsilon$. נסמנו $a_{n_{1}}$
<u>הנחה</u>: נניח שבחרנו $n_{1},\dots,n_{k}$ כך ש
$$
\begin{gather}
a_{n_{1}}\geq \overline{\lim_{ n \to \infty } }a_{n}+\epsilon \\
\vdots \\
a_{n_{k}}\geq \overline{\lim_{ n \to \infty } }a_{n}+\epsilon
\end{gather}
$$
<u>צעד</u>:
לפי ההנחה, עבור $N_{k+1}=n_{k}$ קיים $n_{k+1}>N_{k+1}$ המקיים
$$
a_{n_{k+1}}\geq \overline{\lim_{ n \to \infty } }a_{n}+\epsilon
$$
מתקיים $n_{k+1}>n_{k}$

בנינו את $\left( a_{n_{k}} \right)$ זו לא סדרה מתכנסת, וכן חסומה כי $\left( a_{n} \right)$ חסומה. ולכן לפי [[גבול חלקי#משפט בולצאנו ווירשטראס|BW]] קיימת [[תת סדרה]] מתכנסת $a_{n_{k_{j}}}\xrightarrow{j\to \infty}L$, $\left( a_{n_{k_{j}}} \right)$ תת סדרה של $\left( a_{n} \right)$, ולכן $L\in \mathcal{L}$
$$
L \leq \overline{\lim_{ n \to \infty } a_{n}}=\text{sup}\left( \mathcal{L} \right)
$$
אבל! לכל $k$: $a_{n_{k}}\geq \overline{\lim_{ n \to \infty }}a_{n}+\epsilon$
לכל $j$: $a_{n_{k_{j}}}\geq \overline{\lim_{ n \to \infty }}a_{n}+\epsilon$
ולכן מיחס של גבולות
$$
L=\lim_{ n \to \infty } a_{n_{k_{j}}} \geq \overline{\lim_{ n \to \infty } }a_{n}+\epsilon
$$
וזו סתירה מהטענה ש $L \leq \overline{\lim_{ n \to \infty } a_{n}}=\text{sup}\left( \mathcal{L} \right)$

# תרגיל
הוכיחו או הפריכו
יהיו $\left( a_{n} \right),(b_n)$ חסומות
א.
$$
\overline{\lim_{ n \to \infty } }\left( a_{n}+b_{n} \right) =\overline{\lim_{ n \to \infty } }a_{n}+\overline{\lim_{ n \to \infty } }b_{n}
$$
ב.
$$
\overline{\lim_{ n \to \infty } }\left( a_{n}+b_{n} \right)  \leq \overline{\lim_{ n \to \infty } } a_{n}+\overline{\lim_{ n \to \infty } }b_{n}
$$
## פתרון
א.
לא!, דוגמה נגדית
$$
\begin{gather}
a_{n}=\left( -1 \right)^{n}=\left( -1,1,-1,1,\dots \right)  \\
b_{n}=\left( -1 \right) ^{n+1}=\left( 1,-1,1,-1,\dots \right)  \\
\left( a_{n}+b_{n} \right) =0=\left( 0,0,0,0,\dots \right) 
\end{gather}
$$
ב. כן, נוכיח
$\overline{\lim_{ n \to \infty }}\left( a_{n}+b_{n} \right)$ הוא גבול חלקי של $C_{n}=\left( a_{n}+b_{n} \right)$ ולכן מהגדרה, קיימת תת סדרה $\left( a_{n_{k}} +b_{n_{k}}\right)=c_{n_{k}}$ שמתכנסת ל$\overline{\lim_{ n \to \infty }}\left( a_{n}+b_{n} \right)$

הסדרה $\left( a_{n_{k}} \right)$ לא בהכרח מתכנסת, אבל כן חסומה. לכן לפי BW קיימת סדרה $a_{n_{k_{j}}}\to L$

$\left( a_{n_{k_{j}}}+b_{n_{k_{j}}} \right)\to\overline{\lim_{ n \to \infty }}\left( a_{n}+b_{n} \right)$ כי היא תת סדרה של סדרה מתכנסת

(נוכל לקחת תת סדרה של $\left( b_{n_{k_{j}}} \right)$, להראות שהיא כן מתכנסת ולעבוד משם. אבל במקום זה, נוכיח שהיא עצמה מתכנסת)
$$
b_{n_{k_{j}}} = \left( a_{n_{k_{j}}} +b_{n_{k_{j}}}\right) -a_{n_{k_{j}}}
$$
ולכן $b_{n_{k_{j}}}$ מתכנסת לפי אריתמטיקה של חיסור
$\lim_{ j \to \infty }b_{n_{k_{j}}}=K$, $K$ הוא גבול חלקי של $b_{n}$

$\overline{\lim}\left( a_{n}+b_{k} \right)=\lim_{ j \to \infty }\left( a_{n_{k_{j}}}+b_{n_{k_{j}}} \right)=L+K\leq\overline{\lim}a_{n}+\overline{\lim}b_{n}$
# תרגיל
תהי $\left( a_{n} \right)$ סדרה חסומה, נתון כי $-1,1\in \mathcal{L}$, נתון $\left| a_{n+1}-a_{n} \right|<1$
הוכיחו כי קיים ל$a_{n}$ג"ח נוסף
# פתרון
טענה: בקטע $\left[ -\frac{1}{2}, \frac{1}{2} \right]$קיימים $\infty$  הסדרה

הוכחת הטענה:
נניח בשלילה שבקטע $\left[ -\frac{1}{2}, \frac{1}{2} \right]$ יש מספר סופי של איברים
החל ממקום מסויים (לכל $n>N$) אין בקטע זה אף איבר מ$a_{n}$
בנוסף, $-1 \in \mathcal{L}$ ולכן קיימים אינסוףף מאיברי הסדרה בקטע $\left( -1 \frac{1}{2}, \frac{1}{2} \right)$, בפרט קיים $m>N$ כך ש $a_{m}< \frac{-1}{2}$

$1\in \mathcal{L}$ ולכן קיים $k>m$ כך ש $a_{m}\in \left( \frac{1}{2},1 \frac{1}{2} \right)$
לפי "שורה של כדורים" (מה זה אומר עומרררר)

קיים $t$ כך ש $a_{t} < -\frac{1}{2}$ ו $a_{t+1} > \frac{1}{2}$, לכן $a_{t+1}-a_{t}>1$ וזו סתירה
$\blacksquare$
