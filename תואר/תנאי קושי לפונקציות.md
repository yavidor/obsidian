# הגדרה
פונקציה $f$ מקיימת את תנאי קושי בנקודה $x_{0}$ אם לכל $\epsilon>0$ יש $\delta>0$ כך שאם $0<\left| x-x_{0} \right|<\delta$ ו$0<\left| y-x_{0} \right|<\delta$ אז $\left| f\left( x \right)-f\left( y \right) \right|<\epsilon$

# משפט
לפונקציה $f$ יש גבול בנקודה $x_{0}$ $\iff$ היא מקיימת את תנאי קושי ב$x_{0}$.

## הוכחה
ראשית נוכיח $\impliedby$
נניח ש-$\lim_{ x \to x_{0} }f\left( x \right)=L$
נתון $\epsilon>0$ מהגדרת הגבול. קיים $\delta>0$ כך שאם $0<\left| x-x_{0} \right|<\delta$ אז $\left| f\left( x \right)-L \right|< \frac{\epsilon}{2}$
אם $0<\left| x-x_{0} \right|<\delta$ ו$0<\left| y-x_{0} \right|<\delta$ אז
$$
\left| f\left( x \right) -f\left( y \right)  \right| \leq \left| f\left( x \right) -L \right| + \left| L-f\left( y \right)  \right| <\epsilon
$$

כעת נוכיח $\implies$
נגדיר $a_{n}=x_{0}+\frac{1}{n}$
טענה: הסדרה $f\left( a_{n} \right)$ היא סדרת קושי.
הוכחה: נתון $\epsilon>0$, צריך להוכיח כי קיים $N$ כך שאם $n,m>N$ אז $\left| f\left( a_{n} \right)-f\left( a_{m} \right) \right|<\epsilon$. מכיוון ש$f$ מקיימת את תנאי קושי בנקודה $x_{0}$, קיים $\delta>0$ כך שאם $0<\left| x-x_{0} \right|<\delta$ ו $0<\left| y-x_{0} \right|<\delta$ אז $\left| f\left( x \right)-f\left( y \right) \right|<\epsilon$
מבחר $N= \left\lceil  \frac{1}{\delta}  \right\rceil$ ,אם $n,m>N$ אז $0<\left| a_{n}-x_{0} \right|<\delta$ ו$0<\left| a_{m}-x_{0} \right|<\delta$ ולכן $\left| f\left( a_{n} \right)-f\left( a_{m} \right) \right|<\epsilon$
מכיוון ש$f\left( a_{n} \right)$ סדרת קושי, יש לה גבול. נסמן את הגבול ב-$L$
כעת נראה שמתקיים $\lim_{ x \to x_{0} }f\left( x \right)=L$
יהי $\epsilon>0$, מתנאי קושי נובע שקיים $\delta>0$ כך שלכל $0<\left| x-x_{0} \right|<\delta,0<\left| y-x_{0} \right|<\delta$ מתקיים $\left| f\left( x \right)-f\left( y \right) \right|< \frac{\epsilon}{2}$
מכיוון ש $f\left( a_{n} \right)\to L$ קיים $N$ כך שלכל $n>N$ מתקיים $\left| f\left( a_{n} \right)-L \right|< \frac{\epsilon}{2}$
ניקח $n=\max\left( N-1, \left\lceil  \frac{1}{\delta}  \right\rceil \right)$
נניח ש$0<\left| x-x_{0} \right|<\delta$
וגם $0<\left| a_{n}-x_{0} \right|<\delta$
ולכן $\left| f\left( x \right)-f\left( a_{n} \right) \right|< \frac{\epsilon}{2}$ 
וגם $\left| f\left( a_{n} \right)-L \right|< \frac{\epsilon}{2}$
ולכן $\left| f\left( x \right)-L \right|<\epsilon$
