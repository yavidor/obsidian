# [[פונקציה]] קדומה
אם $F'\left( x \right)=f\left( x \right)$ אז $F$ נקראת <u>פונקציה קדומה</u> של $f$.
# טענה
אם $F$ ו-$G$ הן פונקציות קדומות של $f$, אז קיים קבוע [[מספרים ממשיים|ממשי]] $c\in \mathbb{R}$ כך ש-$G\left( x \right)=F\left( x \right)+c$
# לינאריות
לאינטגרל יש תכונה _לינארית_. כלומר
$$
\int \left( a \cdot f\left( x \right) +b\cdot g\left( x \right)  \right)  \, dx =a\int f\left( x \right) \, dx + b\int g\left( x \right)  \, dx +c ,c\in \mathbb{R}
$$
## הוכחה
נסמן $F\left( x \right)=\int f\left( x \right) \, dx,G\left( x \right)=\int g\left( x \right) \, dx$. יהיו $a,b \in \mathbb{R}$.
מלינאריות של ה[[נגזרת]] מתקיים
$$
\left( a\cdot F\left( x \right) +b\cdot G\left( x \right)  \right)' = a\cdot F\left( x \right)'+b\cdot G'\left( x \right)  = a\cdot f\left( x \right) +b\cdot g\left( x \right)
$$
מכאן, ומהגדרת האינטגרל כפונקציה קדומה נובע כי
$$
\int \left(  a\cdot f\left( x \right) +b\cdot g\left( x \right) \right)  \, dx = a\cdot F\left( x \right) + b \cdot G\left( x \right) 
$$
ומהגדרת $F,G$ כפונקציות הקדומות של $f,g$ בהתאמה מתקבל כי
$$
a\cdot F\left( x \right) +b\cdot G\left( x \right) =a\cdot \int f\left( x \right)  \, dx+b\cdot \int g\left( x \right)  \, dx  
$$
משרשרת השווינות שיצרנו כאן מתקבל כי
$$
\int \left( a\cdot f\left( x \right) +b\cdot g\left( x \right)  \right)  \, dx  = a\cdot\int f\left( x \right)  \, dx + b\cdot\int g\left( x \right)  \, dx 
$$
כנדרש
$\blacksquare$
