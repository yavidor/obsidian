# הגדרה
תהי [[פונקציה]] $f$ המוגדרת בקטע $\left( a,b \right)$ ו[[נגזרת|גזירה]] בנקודה $x_{0}\in \left( a,b \right)$. אם $x_{0}$ [[נקודת קיצון|נקודת קיצון מקומי]] $f$ אזי
$$
f'\left( x_{0} \right) =0
$$

> [!NOTE] מה הביג דיל
> כן, זה נראה טריוויאלי כי זה הדבר הראשון שלימדו אותנו בתיכון על נקודות קיצון ועל נגזרות
> בתיכון הביאו לנו משפטים ותכונות על מגש כסף, הגיע הזמן להשיג את התכונות האלה בעצמנו 

> [!ABSTRACT] מה קורה פה
> נקודת קיצון דורשת סביבה שבה היא הכי נמוכה או הכי גבוהה.
> על מנת שזה יהיה נכון הפונקציה צריכה "לרדת" על מנת להגיע אליה ואז "לעלות" בחזרה (או להפך). אם כך השיפוע צריך להיות שלילי ואז חיובי, אבל בנקודה עצמה השיפוע לא יכול להיות חיובי או שלילי כי אז הנקודה לא תהיה מקסימום/מינימום
# הוכחה
תהא פונקציה $f$ המוגדרת בקטע $\left( a,b \right)$ עם נקודת קיצון מקומית $x_{0}\in \left( a,b \right)$. צריך להראות כי $f'\left( x_{0} \right)=0$. נניח בה"כ כי $x_{0}$ נקודת מינימום מקומי (ונראה בסוף מדוע ההוכחה זהה עבור מקסימום מקומי)
נוכיח באמצעות [[גבול חד צדדי|גבולות חד-צדדיים]]. כלומר נראה ש
$$
\lim_{ x \to x_{0}^{+} } \frac{f\left( x \right)-f\left( x_{0} \right) }{x-x_{0}}=\lim_{ x \to x_{0}^{-} } \frac{f\left( x \right) -f\left( x_{0} \right) }{x-x_{0}}
$$
ראשית נסתכל על הגבול החד-צדדי מימין, בגלל ש-$x_{0}$ נקודת מינימום מקומית, בסביבתה הימנית מתקיים $f\left( x \right)\geq f\left( x_{0} \right)$ ו $x\geq x_{0}$
ולכן
$$
f\left( x \right) -f\left( x_{0} \right) \geq 0 \land x -x_{0} \geq 0 \implies \frac{f\left( x \right) -f\left( x_{0} \right) }{x-x_{0}} \geq 0
$$
כעת נסתכל על הגבול החד-צדדי משמאל, בגלל ש-$x_{0}$ נקודת מינימום מקומית, בסביבתה השמאלית מתקיים $f\left( x \right)\geq f\left( x_{0} \right)$ ו $x\leq x_{0}$
ולכן
$$
f\left( x \right) -f\left( x_{0} \right) \geq 0 \land x-x_{0} \leq 0 \implies \frac{f\left( x \right) -f\left( x_{0} \right) }{x-x_{0}} \leq 0
$$
נתון לי ש-$f$ גזירה ב-$x_{0}$ ולכן הגבול $\lim_{ x \to x_{0} } \frac{f\left( x \right)-f\left( x_{0} \right)}{x-x_{0}}$ קיים, מה שאומר שהגבולות החד-צדדים שלו שווים.
אזי
$$
0 \leq \lim_{ x \to x_{0}^{+} } \frac{f\left( x \right) -f\left( x_{0} \right) }{x-x_{0}}=\lim_{ x \to x_{0} } \frac{f\left( x \right) -f\left( x_{0} \right) }{x-x_{0}}=\lim_{ x \to x_{0}^{-} }  \frac{f\left( x \right) -f\left( x_{0} \right) }{x-x_{0}}\leq 0
$$
אזי
$$
0\leq \lim_{ x \to x_{0} } \frac{f\left( x \right) -f\left( x_{0} \right) }{x-x_{0}}\leq 0 \implies \lim_{ x \to x_{0} } \frac{f\left( x \right) -f\left( x_{0} \right) }{x-x_{0}}= 0
$$
$\blacksquare$
