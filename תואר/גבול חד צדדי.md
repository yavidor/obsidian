# הגדרה
תהא $f$  [[פונקציה]] המוגדרת בקטע $\left( x_{0},x+\delta_{0} \right)$ נאמר שהגבול ממין של $f$ ב$x_{0}$ הוא $L$ ונסמן $\lim_{ x \to x_{0} }f\left( x \right)=L$  אם
$$
\left( \forall\epsilon>0 \right)\left( \exists\delta >0\right) \left( \forall x \right) :x \in \left( x_{0},x_{0}+\delta \right) \implies \left| f\left( x \right) -L \right| <\epsilon
$$
באותו אופן מגדירים את הגבול משמאל עבור $f$ המוגדרת בקטע $\left( x_{0}-\delta,x_{0} \right)$ נאמר שהגבול משמאל של $f$ מ$x_{0}$ הוא $L$ ונסמן $\lim_{ x \to x_{0} }f\left( x \right)$ אם
$$
\left( \forall\epsilon>0 \right) \left( \exists\delta>0 \right) \left( \forall x \right) :x \in \left( x_{0}-\delta,x_{0} \right)  \implies \left| f\left( x \right) -L \right| <\epsilon
$$
# משפט על גבול שלם
תהא $f$ מוגדרת בסביבה נקובה של $x_{0}$, אזי הטענות הבאות שקולות
1. $\lim_{ x \to x_{0} }f\left( x \right)=L$
2. $\lim_{ x \to x_{0}^{+} }f\left( x \right)=L=\lim_{ x \to x_{0}^{-} }f\left( x \right)$
(אותו דבר, כתיבה אחרת)
$$
\lim_{ x \to x_{0}^{-} }f\left( x \right)  =\lim_{ x \to x_{0}^{+} } f\left( x \right) =L \iff \lim_{ x \to x_{0} } f\left( x \right) =L
$$
## הוכחה
ראשית $2 \impliedby 1$
יהא $\epsilon>0$ מאחר ו$\lim_{ x \to x_{0} }f\left( x \right)=L$, קיים $\delta>0$ כך שלכל $x$ עבורו $0<\left| x-x_{0} \right|<\delta$ מתקיים $\left| f\left( x \right)-L \right|<\epsilon$ לכן
$$
x \in \left( x_{0},x_{0}+\delta \right) \implies \left| f\left( x \right) -L \right| <\epsilon \implies \lim_{ x \to x_{0}^{+} } f\left( x \right) =L
$$
וגם
$$
x \in \left( x_{0} -\delta, x_{0} \right) \implies \left| f\left( x \right) -L \right| <\epsilon \implies \lim_{ x \to x_{0}^{-} } f\left( x \right) =L 
$$
עכשיו $1 \impliedby 2$
יהא $\epsilon>0$
$$
\lim_{ x \to x_{0}^{+} } f\left( x \right) =L\implies (\exists\delta_{1}>0):(x \in \left( x_{0},x_{0}+\delta_{1} \right) \implies \left| f\left( x \right) -L \right| <\epsilon )
$$
בנוסף
$$
\lim_{ x \to x_{0}^{+} } f\left( x \right) =L\implies (\exists\delta_{2}>0):(x \in \left( x_{0}-\delta_{2},x_{0} \right) \implies \left| f\left( x \right) -L \right| <\epsilon )
$$

לכן עבור $\delta=\min\left\{ \delta_{1},\delta_{2} \right\}$ מתקיים
$$
0<\left| x-x_{0} \right| <\delta \implies \left| f\left( x \right) -L \right| <\epsilon
$$
# משפט גבול חד צדדי של פונקציה מונוטונית
תהא $f$ מונוטונית המוגדרת בקטע $I=\left( a,b \right)$, אזי לכל $x \in I$, הגבולות החד צדדים $\lim_{ x \to x_{0}^{+} }f\left( x \right),\lim_{ x \to x_{0}^{-} }f\left( x \right)$ קיימים, אבל לאו דווקא שווים
## הוכחה
נניח בה"כ כי $f$ לא יורדת
נוכיח כי $\lim_{ x \to x_{0}^{-} }f\left( x \right)$ קיים (באופן דומה, גם $\lim_{ x \to x_{0}^{+} }f\left( x \right)$) 
נגדיר $L:=\text{sup}\left\{ f\left( x \right):x<x_{0} \right\}$, נוכיח כי $\lim_{ x \to x_{0}^{-} }f\left( x \right)=L$
יהא $\epsilon>0$, קיים $\delta>0$ כך ש$L>f\left( x_{0}-\delta \right)>L-\epsilon$ על פי [[חסמים#למת הסופרימום|למת הסופרימום]], כמו כן $f$ מונוטונית ולכן לכל $x \in \left( x_{0}-\delta,x_{0} \right)$  מתקיים $L\underset{ \text{sup} }{ \geq } f\left( x \right)\geq f\left( x_{0}-\delta \right)>L-\epsilon$
זה גורר כי $\left| f\left( x \right)-L \right|<\epsilon$
